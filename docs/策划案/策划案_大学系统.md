# 大学系统策划案

## 1. 系统概述

### 1.1 基本定位

大学系统以"艾瑟顿社区大学"为背景，是游戏中玩家角色成长的核心途径之一。玩家可以在大学中报名专业、按照固定课表上课、积累学业经验并逐步升级，最终从专业毕业。系统提供四个风格各异的专业方向，涵盖战斗、魔法、信仰和生活技能，满足不同玩家的培养偏好。

### 1.2 核心玩法循环

```
报名专业 → 查看课表 → 按时上课 → 获取经验 → 学业升级 → 属性/战斗加成 → 毕业
```

### 1.3 设计原则

- **固定课表制**：每个专业每周固定三节课，每节90分钟，玩家需在课程时间窗口内前往上课。
- **多专业并行**：玩家最多同时修读2个专业，且任意两个专业的课程时间互不冲突。
- **进度保留**：退学后学业进度（等级、经验）保留，重新报名可继续学习。
- **校园沉浸**：除了上课，大学还提供花园散步、社团活动、同学聊天等丰富的校园生活内容。

## 2. 专业设置

大学共开设4个专业，每个专业有独立的属性加成方向和特色机制。

### 2.1 专业一览表

| 专业 | 图标 | 定位 | 五维加成（每升级） | 战斗加成（每升级） | 每节课经验 | 特殊机制 |
|------|------|------|-------------------|-------------------|-----------|---------|
| 战士学 | ⚔️ | 近战/体能 | 力量+2, 耐力+1 | 物理伤害+5% | 15 | -- |
| 魔法学 | 🔮 | 法术/魔力 | 魅力+2, 灵感+1 | 魔法伤害+5% | 15 | -- |
| 神学 | 📿 | 信仰/治愈 | 灵感+2, 魅力+1 | 魔法抗性+3% | 15 | -- |
| 烹饪学 | 🍳 | 料理/生活 | 技巧+2, 耐力+1 | 无 | 20 | 每节课额外获得10点烹饪经验 |

### 2.2 专业详细描述

**战士学**
学习近战格斗、武器使用和体能训练。修完后大幅提升力量和战斗能力。课程侧重实战技巧，从基础剑术到战术兵法再到实战对练，循序渐进。

**魔法学**
研究元素法术、符文刻印和魔力控制。修完后掌握强大的魔法力量。课程从理论学习到符文描绘再到实际施法，体系完整。

**神学**
钻研神圣经典、治愈祷告和神谕解读。修完后大幅提升灵感与信仰之力。课程包含经典诵读、文本解读与冥想修行。

**烹饪学**
从基础刀工到高级料理，系统学习烹饪技艺。修完后可解锁更多食谱，还能开小摊赚钱。除常规学业经验外，每节课还额外获得烹饪系统经验。

### 3.3 上课时间窗口机制

- 玩家必须在**课程开始时间到课程结束时间之间**进入教学楼才能上课。
- 例如09:00开课、90分钟的课程，玩家需在09:00-10:30之间到达。
- 每节课每天只能上一次，上过的课标记为已出勤。
- 上课后游戏时间自动推进到课程结束时刻。
- 迟到也可以上课（只要在时间窗口内），但时间消耗按剩余时长计算（最少30分钟）。

### 3.4 课程提醒

- 到达课程开始的整点小时时，若该节课尚未出勤且未毕业，系统自动弹出通知提醒。
- 提醒格式：`[专业名]「课程名」HH:MM 在[地点]开课了！`

### 3.5 每日重置

- 每日切换时（由 TimeSystem 触发），重置当天出勤记录，所有课程恢复可出勤状态。

## 4. 学业等级与经验系统

### 4.1 等级体系

学业共6个等级（含初始状态），通过积累学业经验逐步升级。

| 等级 | 名称 | 累计经验要求 | 升级所需经验（与上级差值） |
|------|------|------------|------------------------|
| 0 | 未入学 | 0 | -- |
| 1 | 初学者 | 40 | 40 |
| 2 | 学徒 | 100 | 60 |
| 3 | 进阶 | 180 | 80 |
| 4 | 高级 | 280 | 100 |
| 5 | 毕业 | 400 | 120 |

### 4.2 经验获取途径

| 途径 | 经验量 | 说明 |
|------|-------|------|
| 正常上课 | 15（烹饪学为20） | 主要经验来源 |
| 请教老师（课外辅导） | 5 | 花费10金币 + 30分钟 |
| 读书会（社团活动） | 3 | 花费30分钟，随机加到已报名专业之一 |
| 剑术社练习（战士学专属） | 3 | 花费30分钟 |

### 4.3 升级奖励

每次升级时，玩家获得以下奖励：

1. **五维属性永久加成**：根据专业类型增加对应属性值（详见2.1表格）。
2. **战斗加成**：对应专业的战斗属性百分比提升（累计叠加）。
3. **生活经验**：+50点生活经验（通过 WorkSystem）。
4. **系统通知**：显示升级详情和具体加成内容。
5. **日志记录**：在日期日志中记录升级事件。

### 4.4 毕业

- 当学业等级达到5级（累计400经验）时，该专业标记为毕业。
- 毕业后该专业的课不再可上（已达成最高等级）。
- 毕业时弹出特殊祝贺通知。
- 毕业后仍可在社团等场景进行交互（如剑术社指导后辈）。

### 4.5 战斗加成汇总

战斗加成以百分比形式累加到全局状态中，供战斗系统读取。

| 加成类型 | 来源专业 | 每级增量 | 满级（5级）总增量 |
|---------|---------|---------|-----------------|
| 物理伤害 | 战士学 | +5% | +25% |
| 魔法伤害 | 魔法学 | +5% | +25% |
| 魔法抗性 | 神学 | +3% | +15% |

## 5. 上课详细流程

### 5.1 前置条件

- 已报名该专业且未毕业（等级 < 5）
- 当前游戏时间处于该课程的时间窗口内
- 今日该课程尚未出勤
- 持有足够金币（每节课15金币学费）

### 5.2 上课消耗与产出

| 项目 | 数值 |
|------|------|
| 金币消耗 | -15 |
| 时间消耗 | 推进至课程结束（至少30分钟） |
| 疲劳增加 | +8 |
| 压力减少 | -2 |
| 学业经验 | +15（烹饪学+20） |
| 烹饪经验（仅烹饪学） | +10 |
| 知识经验 | +10（对应知识领域） |
| 生活经验（升级时） | +50 |

### 5.3 知识经验联动

上课同时增加对应知识领域的经验（通过 WorkSystem.addKnowledgeExp）：

| 专业 | 对应知识领域 | 每节课知识经验 |
|------|------------|--------------|
| 战士学 | 战术学 (tactics) | +10 |
| 魔法学 | 魔法理论 (magicTheory) | +10 |
| 神学 | 神学 (theology) | +10 |
| 烹饪学 | 烹饪理论 (cookTheory) | +10 |

### 5.4 首次上课赠送教材

每个专业首次上课时赠送一本教材，可在家中阅读以获得额外知识经验。

| 专业 | 教材名称 |
|------|---------|
| 战士学 | 《战术学教材》 |
| 魔法学 | 《魔法理论概论》 |
| 神学 | 《神学经典诠释》 |
| 烹饪学 | 《烹饪学原理》 |

### 5.5 关键词收集联动

上课过程中有概率触发关键词系统（KeywordSystem）收集：

| 专业 | 收集关键词 | 概率 |
|------|-----------|------|

每节课上课时随机展示一段沉浸式场景描述。每个专业的3门课程各有3条随机描述文本，总计36条课堂场景文本，保证重复游玩时的新鲜感。

## 6. 校园地图与交互场景

大学校园包含以下可探索区域，每个区域提供不同的交互选项。

### 6.1 大学校门（主界面）

- 显示当前星期、时间
- 显示今日课表摘要（含课程状态：上课中/已结束/已出勤/已毕业）
- 显示已报名专业概况（名称、等级、经验进度）
- 可前往：教学楼、公告栏、花园、教师办公室、社团活动室
- 已入学可触发：和同学聊天

### 6.2 公告栏

- 展示全校完整周课表（按星期排列，含所有专业课程）
- 显示学费信息（每节课15金币）和专业数量限制（最多2个）
- 提供报名入学入口（未满时）和退学入口（已报名时）

### 6.3 教学楼

- 显示当日课程状态分三类：正在上课（可进入）、今日待上、已完成/已过
- 提供上课操作入口（仅对当前时间窗口内的课程有效）
- 未报名时引导前往公告栏

### 6.4 花园

- 提供两种休闲活动：
  - **长椅休息**：15分钟，压力-5
  - **小径散步**：20分钟，压力-8，疲劳+2
- 随机场景描述增加沉浸感

### 6.5 教师办公室

- **查看学业成绩**：显示所有已报名专业的等级、经验进度、累计课时和战斗加成
- **课外辅导**：花费10金币 + 30分钟，获得5点学业经验，疲劳+3（需已报名且未毕业）
- 每个已报名且未毕业的专业都可单独请教

### 6.6 社团活动室

提供以下社团活动：

| 社团 | 条件 | 耗时 | 效果 |
|------|------|------|------|
| 读书会 | 无 | 30分钟 | 压力-5，疲劳+2，随机一个已报名专业经验+3 |
| 棋艺社 | 无 | 30分钟 | 压力-3，随机趣味文本 |
| 美食社 | 已报名烹饪学 | 30分钟 | 饱食度+10，烹饪经验+5 |
| 剑术社 | 已报名战士学 | 30分钟 | 疲劳+5，战士学经验+3（已毕业则无经验，改为叙事文本） |

### 6.7 和同学聊天

- 需已入学才可触发
- 消耗15分钟
- 从6条随机聊天事件中抽取一条，每条有不同的效果（压力减少、饱食度增加等）
- 部分事件有额外判定条件（如购买三明治需3金币）

## 7. 报名与退学机制

### 7.1 报名流程

1. 前往公告栏 → 点击"报名入学"
2. 查看专业列表（已报名的专业标灰显示）
3. 选择专业 → 进入专业介绍页（展示课程安排、学费、升级加成等详情）
4. 确认报名 → 入学成功
5. 若该专业有历史进度，将恢复原有等级和经验继续学习

### 7.2 报名限制

- 最多同时报名2个专业
- 专业已满时点击报名会提示需先退学一个

### 7.3 退学流程

1. 前往公告栏 → 点击"退学"
2. 选择要退出的专业
3. 确认退学 → 退学成功
4. 退学后等级和经验保留，重新报名可继续

### 7.4 存档兼容

系统支持从旧版单专业存档数据自动迁移到新版多专业数据结构，确保存档向后兼容。

## 8. 与其他系统的集成

### 8.1 GameState（核心状态）

| 交互方式 | 说明 |
|---------|------|
| `GameState.state` | 读写玩家所有大学相关持久化数据（专业列表、等级、经验、出勤记录、金币、疲劳、压力、饱食度等） |
| `GameState.modStat()` | 升级时增加五维属性 |
| `GameState.showNotification()` | 显示升级、上课、提醒等通知 |
| `GameState.addDateLog()` | 记录入学、退学、升级等关键事件到日期日志 |

### 8.2 TimeSystem（时间系统）

| 交互方式 | 说明 |
|---------|------|
| `TimeSystem.addMinutes()` | 上课、辅导、社团活动等推进游戏时间 |
| 每小时回调 | 由 TimeSystem 的小时刻度调用 `checkClassReminder()` 进行上课提醒 |
| 每日切换 | 由 TimeSystem 的日切换调用 `onDayChange()` 重置出勤记录 |

### 8.3 WorkSystem（工作/生活系统）

| 交互方式 | 说明 |
|---------|------|
| `WorkSystem.addLifeExp()` | 学业升级时增加50点生活经验 |
| `WorkSystem.addKnowledgeExp()` | 上课时增加对应知识领域经验（每次+10） |

### 8.4 CookingSystem（烹饪系统）

| 交互方式 | 说明 |
|---------|------|
| `CookingSystem.addCookingExp()` | 烹饪学上课时额外增加10点烹饪经验 |
| 美食社活动 | 增加5点烹饪经验 |

### 8.5 KeywordSystem（关键词系统）

| 交互方式 | 说明 |
|---------|------|
| `KeywordSystem.collectKeyword()` | 上课时自动收集与专业相关的关键词，用于触发其他系统内容解锁 |

### 8.6 BattleSystem（战斗系统）

| 交互方式 | 说明 |
|---------|------|
| `UniSystem.getCombatBonuses()` | 提供统一接口供战斗系统查询当前物理伤害/魔法伤害/魔法抗性的百分比加成 |

## 9. 数值平衡参考

### 9.1 毕业所需资源估算

以单专业为例，从0级到5级毕业需要累计400点经验：

- **纯上课路线**：400 / 15 = 约27节课（烹饪学为 400 / 20 = 20节课）
- 每周3节课，约需9周（烹饪学约7周）
- **金币总投入**：27 x 15 = 405金币（烹饪学为300金币）
- **总课时时间**：27 x 90分钟 = 2430分钟（约40.5小时游戏内时间）

### 9.2 辅助加速

若充分利用课外辅导和社团活动，毕业周期可缩短约20%-30%。

### 9.3 经济压力

每节课15金币的学费配合其他生活开销，形成金币消耗压力，鼓励玩家在学习和工作之间做时间分配决策。

## 10. 持久化数据结构

系统在 `GameState.state` 中维护以下关键字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `uniEnrolled` | boolean | 是否已入学（至少报名一个专业） |
| `uniMajors` | string[] | 当前报名的专业ID列表（最多2个） |
| `uniMajorData` | table | 各专业的详细数据，键为专业ID |
| `uniMajorData[id].level` | number | 该专业当前等级（0-5） |
| `uniMajorData[id].exp` | number | 该专业累计经验 |
| `uniMajorData[id].totalClasses` | number | 该专业累计上课次数 |
| `uniAttendedToday` | table | 今日出勤记录（键为 `专业ID_课程索引`） |
| `uniCombatBonus_phys` | number | 物理伤害加成（小数，如0.15表示+15%） |
| `uniCombatBonus_magic` | number | 魔法伤害加成 |
| `uniCombatBonus_mdef` | number | 魔法抗性加成 |
