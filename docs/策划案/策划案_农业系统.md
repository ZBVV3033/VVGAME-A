# 农业系统策划案

> 所属项目：悠闲悠哉life  
> 对应模块：`systems/FarmingSystem.lua`  
> 关联系统：GameState、TimeSystem、CookingSystem、KeywordSystem

---

## 一、系统概述

农业系统是玩家日常生活的核心玩法之一。玩家在家门口拥有一小片空地，可以进行**播种、浇水、收获**等种田活动。收获的作物会自动存入食材背包，可供烹饪系统使用（做菜、出摊售卖），形成"种地 -> 收获 -> 烹饪 -> 赚钱/恢复饱食度"的完整经济循环。

### 设计目标

- 提供轻量化、低压力的日常种田体验，契合"悠闲生活"主题
- 引入每日浇水节奏，鼓励玩家形成规律的游玩习惯
- 通过作物产出衔接烹饪系统，构成自给自足的生活链路
- 收获时触发话题关键词收集，丰富社交对话内容

## 二、农田与地块管理

### 2.1 地块数量

玩家在家门口共有 **3 块田垄**，游戏开始时全部为空地状态。

| 地块编号 | 初始状态 | 说明 |
|:--------:|:--------:|------|
| 第 1 块地 | 空地 | 可立即使用 |
| 第 2 块地 | 空地 | 可立即使用 |
| 第 3 块地 | 空地 | 可立即使用 |

### 2.2 地块数据结构

每块地独立记录以下信息：

| 字段 | 说明 |
|------|------|
| crop | 当前种植的作物名称（空地时为空） |
| plantDay | 播种时的游戏日数 |
| stage | 生长阶段（0~4，详见下方） |
| watered | 今日是否已浇水（每天重置） |

### 2.3 升级系统

当前版本地块数量固定为 3 块，暂无升级扩展机制。所有地块从游戏开始即可使用，无需解锁。

## 四、生长阶段

作物从播种到成熟共经历 **5 个阶段**（含空地状态）：

| 阶段编号 | 名称 | 图标 | 说明 |
|:--------:|:----:|:----:|------|
| 0 | 空地 | 白色方块 | 无作物，可播种 |
| 1 | 已播种 | 棕色方块 | 刚播下种子，等待发芽 |
| 2 | 发芽了 | 嫩芽 | 开始生长 |
| 3 | 生长中 | 绿叶 | 持续生长 |
| 4 | 成熟了! | 麦穗 | 可以收获 |

### 生长规则

- 每个游戏日结束时（日期变更），系统检查所有地块
- **只有当天浇过水的作物才会推进一个生长阶段**
- 未浇水的作物当天不生长，但也不会枯萎或退化
- 阶段到达 4（成熟）后停止生长，等待玩家收获
- 成熟时系统弹出通知提醒玩家

### 生长时间线示例（以土豆为例，每天浇水）

| 日期 | 操作 | 阶段变化 |
|:----:|:----:|:--------:|
| 第 1 天 | 播种 + 浇水 | 0 -> 1（播种），当日浇水 |
| 第 2 天（日更新） | 生长 | 1 -> 2（发芽），需再浇水 |
| 第 3 天（日更新） | 生长 | 2 -> 3（生长中），需再浇水 |
| 第 4 天（日更新） | 生长 | 3 -> 4（成熟！可收获） |

> 注意：如果漏浇一天，成熟时间会相应延后一天，但作物不会死亡。

## 五、核心操作

### 5.1 购买种子

- 种子在**商业区超市**购买（当玩家没有种子时，界面会提示前往超市）
- 购买后种子存入独立的**种子背包**（`farmSeeds`），与食材背包分离
- 种子背包以"名称 -> 数量"形式存储，可同时持有多种种子

### 5.2 播种

- **前提条件**：有空闲地块 + 种子背包中有种子
- **操作流程**：进入家门口空地 -> 选择"播种" -> 选择种子种类 -> 选择目标地块
- **消耗**：1 颗种子、15 分钟游戏时间
- **结果**：地块状态更新为"已播种"（阶段 1），记录作物名称和播种日期
- **限制**：每块地同时只能种一种作物，已有作物的地块不能重复播种

### 5.3 浇水

- **前提条件**：地块有作物且未成熟且今日未浇水
- **操作方式**：
  - **单块浇水**：选择具体地块浇水，消耗 5 分钟
  - **一键全部浇水**：当有 2 块以上需浇水的地块时出现此选项，消耗 5 分钟 x 地块数
- **每日重置**：每天日期变更时，所有地块的浇水状态重置为"未浇水"
- **界面提示**：已浇水地块显示水滴图标，未浇水显示沙漠图标

### 5.4 收获

- **前提条件**：地块作物阶段达到 4（成熟）
- **操作方式**：
  - **单块收获**：收获指定地块，消耗 5 分钟
  - **一键全部收获**：当有 2 块以上成熟地块时出现此选项，消耗 10 分钟
- **产出**：根据作物的产量范围（yield）随机生成数量，存入食材背包
- **地块重置**：收获后地块恢复为空地（阶段 0），可再次播种
- **收获通知**：界面展示收获的作物名称和数量

### 5.5 施肥

当前版本暂未实现施肥机制。作物的生长速度完全由浇水决定。

## 六、季节效果

当前版本暂未实现季节系统对农业的影响。所有作物在任何时间均可种植和正常生长，不受月份或季节限制。

## 七、系统联动

### 7.1 与 GameState（游戏状态）的联动

农业系统的所有数据存储在 GameState 的全局状态中：

| 状态字段 | 类型 | 说明 |
|----------|------|------|
| `farmPlots` | 数组（3个元素） | 三块地的完整状态 |
| `farmSeeds` | 键值对 | 种子背包（种子名 -> 数量） |
| `ingredients` | 键值对 | 食材背包（食材名 -> 数量），与烹饪系统共享 |

这些数据随存档系统（SaveSystem）一起持久化，支持读档恢复。

### 7.2 与 TimeSystem（时间系统）的联动

| 触发时机 | 行为 |
|----------|------|
| 每日日期变更 | TimeSystem 调用 `FarmingSystem.onDayChange()`，推进已浇水作物的生长阶段，重置所有浇水状态 |
| 播种操作 | 消耗 15 分钟游戏时间 |
| 单块浇水 | 消耗 5 分钟游戏时间 |
| 单块收获 | 消耗 5 分钟游戏时间 |
| 一键全部浇水 | 消耗 5 分钟 x 地块数 |
| 一键全部收获 | 消耗 10 分钟游戏时间 |

时间消耗会正常触发 TimeSystem 的小时更新逻辑（饱食度下降、疲劳增长等），因此高强度农作也需注意角色状态管理。

### 7.3 与 CookingSystem（烹饪系统）的联动

农业系统收获的作物直接存入食材背包（`ingredients`），烹饪系统从同一背包读取食材。以下食谱使用了可种植的作物作为原料：

| 食谱 | 需要的种植作物 | 烹饪等级 | 售价 |
|------|:------------:|:--------:|:----:|
| 烤土豆 | 土豆 x2 | 入门 | 12 |
| 蔬菜汤 | 白菜 x1、胡萝卜 x1 | 入门 | 15 |
| 番茄炒蛋 | 番茄 x2 | 熟练 | 20 |
| 洋葱鸡肉卷 | 洋葱 x1、小麦 x1 | 熟练 | 25 |
| 猪肉饺子 | 小麦 x2、白菜 x1 | 精通 | 40 |

通过种植获取食材可以大幅降低烹饪成本（无需在超市购买蔬菜），是玩家经济体系的重要组成部分。

### 7.4 与 KeywordSystem（关键词/话题系统）的联动

收获作物时会触发关键词收集：

| 关键词 | 触发条件 | 分类 | 说明 |
|--------|----------|:----:|------|
| `crop_harvest`（丰收体验） | 每次收获必定触发 | 园艺 | 解锁与 NPC 讨论种田心得的对话选项 |
| `rare_seed`（稀有种子） | 每次收获有 15% 概率触发 | 园艺 | 解锁稀有种子相关话题 |

这些关键词可以在与 NPC 的闲聊中使用，不同角色对"园艺"类话题有不同的兴趣等级，会产生不同的好感度加成和对话反应。例如，与莱德聊"丰收体验"时，他会表现出温柔的兴趣并主动索要作物。

## 八、界面与交互流程

### 8.1 主界面（家门口空地）

进入"家_门口空地"后，玩家看到：

- 场景描述文本（三块田垄沐浴在阳光下）
- 三块地的状态一览（图标 + 作物名 + 生长阶段 + 浇水状态）
- 种子背包当前内容
- 根据当前状态动态显示的操作按钮

### 8.2 动态按钮逻辑

| 条件 | 显示按钮 |
|------|----------|
| 有未浇水且未成熟的作物 | "浇水" |
| 有成熟的作物 | "收获" |
| 有空地 + 有种子 | "播种" |
| 有空地 + 无种子 | "播种（没有种子，去超市买吧）"（点击后提示前往超市） |
| 始终显示 | "回家" |

### 8.3 完整操作流程图

```
家 -> 家门口空地
         |
    +----+----+----+--------+
    |         |    |        |
  播种      浇水  收获    回家
    |         |    |
  选种子    选地块  选地块/全部
    |         |    |
  选地块    完成   收获结果
    |              |
  完成        +----+----+
              |    |    |
           继续种地 去厨房 回家
```

## 九、数值平衡备注

### 时间成本

- 完整种植周期（以胡萝卜为例）：播种 15 分钟 + 浇水 5 分钟 x 2 天 + 收获 5 分钟 = 合计 30 分钟跨 3 个游戏日
- 三块地同时管理：每日浇水约 15 分钟，属于轻量日常活动

### 经济定位

- 种植是**低成本获取蔬菜类食材**的途径，适合前期资金紧张时使用
- 种子价格远低于成品食材价格，形成明确的经济激励
- 真正的收益来自将种植作物加工为料理后出售（例：2 金币白菜种子 -> 白菜 -> 蔬菜汤 -> 卖 15 金币）

### 当前局限

- 无施肥系统（无法加速生长）
- 无季节限制（全年可种植所有作物）
- 无地块升级/扩展机制
- 无害虫/天气灾害事件
- 作物不会枯萎（忘记浇水只延迟生长，不惩罚玩家）

> 以上局限符合"悠闲生活"的设计基调，降低了负面体验，但后续版本可根据需要扩展。
