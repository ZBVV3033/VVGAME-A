# 烹饪系统策划案

## 1. 系统概述

烹饪系统是"悠闲悠哉life"中的核心生活玩法之一，涵盖**食材采购与种植、食谱学习与烹饪、饱食度管理、小摊经营**四大模块。玩家通过购买或种植获取食材，在家中厨房烹饪菜肴来恢复饱食度、减少压力，并随着烹饪等级的提升解锁更多食谱。当烹饪等级达到 2 级后，玩家还可以在商业区摆小摊出售食物赚取金币，形成"采购/种植 -> 烹饪 -> 出售"的完整经济循环。

## 5. 烹饪机制

### 5.1 在家烹饪流程

```
进入家 -> 选择"去厨房做饭" -> 进入食谱列表界面
                                    |
                      查看所有已解锁食谱（按等级过滤）
                      每个食谱显示：名称、所需食材（标注是否充足）、饱食度
                                    |
                  +--------+--------+
                  |                  |
            食材充足             食材不足
           选择烹饪            显示"食材不足"提示
                  |              引导去超市购买
                  |
           消耗食材 -> 增加饱食度 -> 增加疲劳(+5)
                    -> 减少压力(-3 或 -8)
                    -> 获得烹饪经验
                    -> 消耗游戏时间(20分钟)
                    -> 首次制作记录到已知食谱
                  |
           显示烹饪结果文本 -> 返回家
```

### 5.2 烹饪效果

每次在家烹饪成功，产生以下效果：

| 效果 | 数值 | 说明 |
|------|------|------|
| 饱食度增加 | 按食谱的 satiety 值 | 范围 18~55 |
| 压力减少 | 饱食度 >= 35 的菜: -8；其他: -3 | 吃饱了心情更好 |
| 疲劳增加 | +5 | 做饭也会累 |
| 烹饪经验 | 食谱等级 x 3 + 5 | 详见经验表 |
| 时间消耗 | 20 分钟 | 游戏内时间推进 |

### 5.3 无食谱时的备选

如果玩家烹饪等级为 0 且没有任何可用食谱（理论上不会出现，因为等级 0 已有 3 个食谱），厨房界面会显示提示文本，并提供"喝杯热水"选项：

- 喝热水效果：饱食度 +5, 压力 -2, 消耗 5 分钟

## 6. 饱食度系统

### 6.1 基本规则

- 饱食度范围：0 ~ 100
- 初始值：80
- 回复方式：烹饪进食、购买速食、喝热水等
- 消耗方式：随时间自然下降（由 TimeSystem 管理）

### 6.2 饱食度状态描述

| 饱食度范围 | 状态描述 | 文本表现 |
|-----------|---------|---------|
| 80 ~ 100 | 饱足 | "你现在不太饿。" |
| 50 ~ 79 | 正常 | "肚子还不算太饿，但吃点东西也不错。" |
| 20 ~ 49 | 有点饿 | "你觉得有点饿了，该吃点什么。" |
| 0 ~ 19 | 饥饿 | "你的肚子咕咕叫个不停，眼前的食物看起来格外诱人。" |

### 6.3 速食（不需要烹饪）

在超市速食区可直接购买即食食物：

| 食物 | 价格 | 饱食度 | 附加效果 |
|------|------|--------|---------|
| 面包 | 8 金币 | +15 | 无 |
| 三明治 | 15 金币 | +25 | 无 |
| 烤肉便当 | 30 金币 | +45 | 压力 -5 |

> 设计意图：速食价格高于自己做饭的食材成本，且没有烹饪经验收益，但胜在便捷。这鼓励玩家学习烹饪而非一直买速食。

## 7. 小摊经营系统

### 7.1 解锁条件

- 烹饪等级达到 **2 级**
- 升级到 2 级时弹出提示："烹饪等级2 -- 你现在可以去商业区摆小摊了！"

### 7.2 出摊流程

```
前往商业区 -> 选择"小摊"
                |
          查看可出售菜品（需食材充足）
                |
          选择一道菜出售
                |
          消耗食材 -> 随机决定销售量 -> 计算收入
                   -> 增加疲劳(+10)
                   -> 获得烹饪经验
                   -> 消耗游戏时间(60分钟)
                   -> 累计出摊天数 +1
                |
          显示出摊结果 -> 可选择继续出摊或收摊
```

### 7.3 销售量随机机制

每次出摊，系统进行一次 1~100 的随机掷骰，决定基础销售份数：

| 骰点范围 | 概率 | 基础销售量 | 描述文本 |
|----------|------|-----------|---------|
| 1 ~ 20 | 20% | 1 份 | "生意冷清。只卖出去一份。" |
| 21 ~ 60 | 40% | 2 份 | "生意还可以。有几个人来尝了尝你的手艺。" |
| 61 ~ 85 | 25% | 3 份 | "生意不错！不少人被香味吸引过来。" |
| 86 ~ 100 | 15% | 4 份 | "大卖！路人排起了队，有人说这是商业区最好吃的小摊。" |

### 7.4 魅力加成

当玩家的**魅力(ML)属性 >= 5** 时，每次出摊额外多卖 1 份，并附加文本提示："(你的魅力吸引了更多客人 +1份)"。

### 7.5 收入计算

```
实际收入 = 食谱售价 x 实际销售量(基础 + 魅力加成)
```

### 7.6 出摊效果汇总

| 效果 | 数值 |
|------|------|
| 金币收入 | 食谱售价 x 销售量 |
| 疲劳增加 | +10 |
| 烹饪经验 | 食谱等级 x 2 + 3 |
| 时间消耗 | 60 分钟 |
| 累计出摊天数 | +1 |

### 7.7 出摊收入估算（每次出摊）

以概率加权期望计算（不含魅力加成）：

| 食谱 | 售价 | 期望销售量 | 期望收入/次 |
|------|------|-----------|-----------|
| 烤土豆 | 12 | 2.35 | 28.2 |
| 蔬菜汤 | 15 | 2.35 | 35.3 |
| 煎蛋 | 10 | 2.35 | 23.5 |
| 番茄炒蛋 | 20 | 2.35 | 47.0 |
| 洋葱鸡肉卷 | 25 | 2.35 | 58.8 |
| 奶油蘑菇汤 | 30 | 2.35 | 70.5 |
| 红烧鱼 | 35 | 2.35 | 82.3 |
| 猪肉饺子 | 40 | 2.35 | 94.0 |
| 香料烤鸡 | 55 | 2.35 | 129.3 |

> 期望销售量计算：0.2x1 + 0.4x2 + 0.25x3 + 0.15x4 = 2.35 份

## 8. 超市系统

### 8.1 超市结构

"日轮超市"位于商业区，分为以下区域：

| 区域 | 可购买内容 |
|------|-----------|
| 蔬菜谷物区 | 土豆、胡萝卜、白菜、番茄、洋葱、小麦 |
| 肉蛋奶区 | 鸡蛋、鸡肉、猪肉、鱼肉、牛奶、黄油 |
| 调味料区 | 盐、糖、香料 |
| 种子区 | 六种作物种子（联动种植系统） |
| 速食区 | 面包、三明治、烤肉便当（即买即吃） |

### 8.2 购买机制

- 每次购买 1 个单位，可反复购买
- 购买前检查金币是否足够，不足则提示"金币不够！"
- 界面实时显示当前金币余额和食材库存

进入厨房后显示以下信息：

## 10. 与其他系统的集成

### 10.1 GameState（全局状态）

烹饪系统读写以下 GameState 字段：

| 字段 | 类型 | 初始值 | 说明 |
|------|------|--------|------|
| `money` | number | -- | 金币（购买/出摊收入） |
| `satiety` | number | 80 | 饱食度(0~100) |
| `fatigue` | number | 0 | 疲劳(0~100) |
| `stress` | number | -- | 压力(0~100) |
| `cookingLevel` | number | 0 | 烹饪等级(0~4) |
| `cookingExp` | number | 0 | 烹饪经验值 |
| `knownRecipes` | table | {} | 已学会的食谱名列表 |
| `ingredients` | table | {} | 食材背包 {食材名: 数量} |
| `stallOpen` | boolean | false | 今天是否已出摊 |
| `stallRevenue` | number | 0 | 今日小摊收入 |
| `stallDayCount` | number | 0 | 累计出摊天数 |
| `ML` | number | 3 | 魅力属性（影响出摊销量） |

### 10.2 TimeSystem（时间系统）

- 在家烹饪消耗 20 分钟游戏时间
- 出摊卖食物消耗 60 分钟游戏时间
- 喝热水消耗 5 分钟游戏时间
- 时间推进通过 `TimeSystem.addMinutes()` 调用

### 10.3 FarmingSystem（种植系统）

- 超市种子区的种子数据来源于 FarmingSystem.SEEDS
- 种植收获的作物直接写入 `GameState.state.ingredients`，与烹饪系统共用同一食材背包
- 可种植的蔬菜/谷物与烹饪食材一一对应（土豆、胡萝卜、白菜、番茄、洋葱、小麦）

### 10.4 UniversitySystem（大学系统）

- 大学开设"烹饪学"专业，包含三节课程：刀工基础、食材学、实践料理
- 每节烹饪课额外提供 10 点烹饪经验
- 报名烹饪学后可参加"美食社"社团活动（获得 5 点烹饪经验 + 10 饱食度）
- 烹饪专业提升技巧(JQ)+2、能力(NL)+1

### 10.5 KeywordSystem（关键词/话题系统）

烹饪系统在以下时机收集关键词（用于社交对话等系统）：

| 时机 | 关键词 | 分类 | 说明 |
|------|--------|------|------|
| 首次制作新食谱 | `new_recipe`("新食谱") | cooking | 可在社交中分享新菜式 |
| 出摊获得收入 | `stall_income` | commerce | -- |
| 出摊积累经验 | `stall_experience`("摆摊心得") | commerce | 可在社交中分享摆摊经验 |
| 大学烹饪课 | `rare_ingredient`("稀有食材") | cooking | 20%概率触发 |

### 10.6 通知系统

通过 `GameState.showNotification()` 在以下事件触发通知：
- 购买食材成功/金币不足
- 烹饪等级提升
- 烹饪等级达到 2 级时的小摊解锁提示

通过 `GameState.addDateLog()` 记录烹饪升级日志。

## 11. 设计理念与平衡要点

### 11.1 核心循环

```
金币 -> 购买食材/种子
              |
     种植(低成本,需时间) 或 直接购买(高成本,即时)
              |
          获得食材
              |
     +--------+--------+
     |                  |
  在家烹饪           出摊卖食物
  (恢复饱食度)       (赚取金币)
  (减少压力)         (赚取烹饪经验)
  (赚取烹饪经验)     (消耗疲劳更多)
     |                  |
     +--------+---------+
              |
         烹饪升级 -> 解锁更多食谱 -> 更高售价/饱食度
```

### 11.2 平衡设计要点

1. **速食 vs 自己做饭**：速食价格高且无经验收益，鼓励玩家学习烹饪
2. **种植 vs 购买食材**：种植成本低但需等待，购买即时但花费高，提供策略选择
3. **出摊的风险与回报**：销售量随机波动，高级菜品利润更高但食材成本也更高
4. **疲劳管控**：出摊疲劳(+10)高于在家做饭(+5)，限制玩家无限出摊
5. **时间成本**：出摊占用 60 分钟游戏时间，与其他活动（上课、社交、打工）争夺时间
6. **魅力联动**：魅力属性影响出摊销量，鼓励玩家发展多维属性而非只专注烹饪
