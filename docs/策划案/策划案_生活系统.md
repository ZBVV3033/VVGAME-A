## 1. 系统概述

生活系统是游戏的日常循环核心，涵盖时间管理、居家生活、经济活动、社交探索等方面。玩家通过打工赚钱、烹饪进食、种菜收获、上课学习、城镇探索等活动度过每一天，同时推进与 NPC 的关系和主线剧情。

### 1.1 子系统清单

| 子系统 | 文件 | 行数 | 核心功能 |
|--------|------|------|---------|
| 时间系统 | `TimeSystem.lua` | ~300 | 时间流逝、状态衰减、房租管理 |
| 同居系统 | `HomeSystem.lua` | ~2024 | 居家互动、NPC来访、睡眠/洗浴/厨房 |
| 打工系统 | `WorkSystem.lua` | ~1542 | 5种职业、10级职称、工作事件 |
| 烹饪系统 | `CookingSystem.lua` | ~400 | 食谱、食材、摆摊 |
| 农场系统 | `FarmingSystem.lua` | ~300 | 种植、浇水、收获 |
| 大学系统 | `UniversitySystem.lua` | ~250 | 4专业、课程、家教 |
| 城镇探索 | `TownLife.lua` | ~2515 | 7地点、20+ NPC、遭遇事件 |
| 关键词系统 | `KeywordSystem.lua` | ~200 | 16类话题、NPC兴趣对话 |

## 2. 时间系统

### 2.1 时间段划分

| 时间段 | 时间范围 | 可用活动 |
|--------|---------|---------|
| 清晨 | 5:00 - 8:00 | 起床、晨练 |
| 上午 | 8:00 - 12:00 | 工作、上课、城镇探索 |
| 中午 | 12:00 - 14:00 | 午餐、午休 |
| 下午 | 14:00 - 17:00 | 工作、探索、农场 |
| 傍晚 | 17:00 - 20:00 | 购物、社交、达里奥演奏 |
| 晚上 | 20:00 - 22:00 | 夜谈、花街活动 |
| 深夜 | 22:00+ | 贾斯帕巡逻、特殊事件 |

### 2.2 每小时状态变化（Hourly Tick）

| 属性 | 白天变化 | 夜间变化 | 说明 |
|------|---------|---------|------|
| 饱食度 (satiety) | -2 | -2 | 持续消耗 |
| 疲劳度 (fatigue) | +1 | +2 | 夜间加速 |
| 清洁度 (cleanliness) | -1 | -1 | 缓慢下降 |
| 压力 (stress) | 条件 +1 | 条件 +1 | 当饱食≤20 或 疲劳≥70 或 清洁≤20 时 |

### 2.3 房租系统

| 参数 | 数值 |
|------|------|
| 第一周房租 | 300 金币 |
| 后续每周房租 | 700 金币 |
| 最大欠租 | 连续 2 周 |
| 欠租后果 | 被驱逐 |

> **设计意图**: 房租是推动玩家打工的核心经济压力。第一周优惠价让新手有缓冲期。

## 4. 打工与职业系统

### 4.1 五种职业

| 职业 | 地点 | 主属性 | 辅属性 | 特色 |
|------|------|--------|--------|------|
| 酒馆侍者 | 辛奇酒馆 | ML(魅力) | JQ(技巧) | 社交型，熟客互动多 |
| 教堂侍从 | 教堂 | LG(灵感) | NL(耐力) | 文化型，知识获取多 |
| 铁匠学徒 | 铁匠铺 | LL(力量) | NL(耐力) | 体力型，锻造技能成长 |
| 码头工人 | 港口 | NL(耐力) | LL(力量) | 体力型，收入稳定 |
| 管家 | 奥梅尔府邸 | ML(魅力) | ZL(智力) | 高薪型，剧情联动多 |

### 4.2 职称系统（10 级）

每种职业有 10 级职称，从「见习」到「传说」。以酒馆侍者为例：

```
Lv.1 见习侍者 → Lv.2 学徒侍者 → Lv.3 正式侍者 → ...
→ Lv.5 资深侍者 → ... → Lv.10 传说侍者
```

### 4.3 里程碑奖励

| 等级 | 奖励内容 |
|------|---------|
| Lv.3 | 解锁第 1 套工作服 + 特殊能力 |
| Lv.5 | 解锁第 2 套工作服 + 工资加成 |
| Lv.7 | 技能奖励 |
| Lv.10 | 最终成就 |

### 4.4 工作服系统

- 每种职业有 2 套工作服（Lv.3 和 Lv.5 解锁）
- 穿工作服获得工作效率加成

### 4.5 工作执行参数

| 参数 | 数值 |
|------|------|
| 时间消耗 | 60 分钟 / 次 |
| 职业经验 | +20 / 次 |
| 清洁下降 | -8（码头/铁匠），-5（其他） |
| 随机事件概率 | 75% |
| 与莱德同工 | 莱德赚工资分一半给玩家，好感+3 |

### 4.6 工资计算

```
基础工资 = 查表（依职业 × 等级）
特殊加成:
  - 管家: 奥梅尔好感 >= 200 → +15%
  - 通用: 梅菲斯好感 >= 150 → +10%
```

### 4.7 工作随机事件

每种职业 8 个事件，共 40 个工作事件。事件包含属性检定、NPC好感变化、金币奖励等。

#### 各职业事件列表

| 职业 | 事件名 |
|------|--------|
| 酒馆侍者 | 醉酒贵族、托盘危机、神秘来客、K的特调、集市日高峰、失恋吟游诗人、酒馆群架、深夜老常客 |
| 教堂侍从 | 迷路小孩、古旧经文、捐款富商、祈祷者的烦恼、醉汉闯入、孤儿院送餐日、深夜告解、教堂花园修缮 |
| 铁匠学徒 | 冒险者委托、发光矿石、贵族订单、铁匠比试、意外受伤、雨夜流浪铁匠、神秘武器设计图、集市展销 |
| 码头工人 | 可疑货物、暴风雨抢救、水手故事、争抢工位、意外发现、潮汐夜班、外国商船、仓库盘点 |
| 管家 | 贵妇考验、小奥心情、宴会准备、打碎花瓶、梅菲斯来访、庄园花园秘密、深夜窃贼、小奥的请求 |

#### 事件结构

```
事件 {
    desc: 事件描述
    descLeiDe: 与莱德一起时的描述变体
    choices: [
        {
            text: 选项文本
            gold: 金币奖励
            exp: 经验奖励
            npc: 好感NPC
            npcAmt: 好感变化量
            result: 结果描述
            statCheck: {        -- 可选：属性检定
                stat: 检定属性
                threshold: 检定阈值
                knowledgeId: 知识加成来源
                knowledgeBonus: 知识等级降低阈值量
                successResult / failResult
                successGold / failGold
            }
        }
    ]
    choicesLeiDe: 莱德版选项变体
}
```

### 7.2 农场参数

| 参数 | 数值 |
|------|------|
| 地块数量 | 3 块 |
| 生长阶段 | 4 个（播种→发芽→成长→成熟） |
| 播种时间 | 15 分钟 |

| 浇水规则 | 每日必须浇水，否则作物不生长 |

### 7.3 产出循环

```
购买种子 → 播种（15分钟）
  → 每日浇水（5分钟/块）
  → 等待 3-6 天
  → 收获食材
  → 用于烹饪（CookingSystem）或出售
```

## 11. 经济循环设计

### 11.1 收入来源

| 来源 | 估计收入 | 频率 |
|------|---------|------|
| 打工 | 10-50 金/次 | 每次 60 分钟 |
| 工作事件奖励 | 5-30 金 | 75% 触发率 |
| 摆摊卖菜 | 变动 | 烹饪等级 ≥ 2 |
| 随机事件奖励 | 5-25 金 | 概率性 |
| 支线任务奖励 | 15-25 金 | 一次性 |

### 11.2 支出项目

| 支出 | 金额 | 频率 |
|------|------|------|
| 房租 | 300-700 金 | 每周 |
| 大学学费 | 15 金/节 | 自选 |
| 家教 | 10 金/次 | 自选 |
| 速食 | 8-30 金/次 | 日常 |
| 食材 | 3-15 金/种 | 烹饪需要 |
| 种子 | 4-15 金/种 | 农场需要 |
| 算命 | 5 金/次 | 随机事件 |

### 11.3 经济平衡分析

```
每日最低消费: 速食面包 8 金 × 2 = 16 金
每日基础收入: 打工 1 次 ≈ 20-30 金
每周房租: 700 金 → 日均 100 金
每日需要收入: ≈ 116 金 → 需打工 3-4 次 或 打工+副业组合
```

> **设计意图**: 经济压力迫使玩家合理规划时间，在打工、社交、主线推进之间做出取舍。烹饪和农场系统提供了降低食物成本的途径。

## 12. 系统交互关系图

```
                     ┌─────────────┐
                     │ TimeSystem  │
                     │  (核心时钟)  │
                     └──────┬──────┘
                            │ 驱动所有时间流逝
              ┌─────────────┼─────────────┐
              ↓             ↓             ↓
     ┌────────────┐  ┌───────────┐  ┌──────────┐
     │ HomeSystem │  │WorkSystem │  │ TownLife │
     │  (居家生活) │  │ (打工职业) │  │(城镇探索) │
     └─────┬──────┘  └─────┬─────┘  └────┬─────┘
           │               │              │
    ┌──────┼──────┐        │         ┌────┼────┐
    ↓      ↓      ↓        ↓         ↓    ↓    ↓
 Cooking Farming  NPC   Knowledge  NPC  Keyword Random
 System  System  来访    System   遭遇  System  Events
    ↑               ↑             ↑      │
    │               │             │      ↓
    └───────────────┴─────────────┴── NPCSystem
                                      (好感度)
                    
 University ──→ Knowledge ──→ WorkSystem (检定加成)
```

### 核心循环

1. **生存循环**: 时间流逝 → 状态衰减 → 吃饭/睡觉/洗澡恢复
2. **经济循环**: 打工赚钱 → 交房租/买食材 → 烹饪/摆摊
3. **成长循环**: 打工经验 → 升级 → 属性点 → 更高效打工
4. **社交循环**: 城镇探索 → 遇见NPC → 好感提升 → 解锁事件/剧情
5. **知识循环**: 读书/上课 → 知识经验 → 工作检定加成 → 更好的事件结果
6. **自给自足循环**: 种菜 → 收获食材 → 烹饪 → 恢复饱食/摆摊赚钱
