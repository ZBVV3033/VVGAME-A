# 时间系统策划案

> 本文档从 `scripts/systems/TimeSystem.lua` 提取，描述游戏内时间流逝、日期变更及其对各系统的联动影响。

---

## 一、时间单位与结构

游戏采用 **分钟 - 小时 - 天 - 周** 四级时间结构：

| 层级 | 范围 | 说明 |
|------|------|------|
| 分钟 | 0-59 | 最小时间单位，各行为消耗不同分钟数 |
| 小时 | 0-23 | 每满 60 分钟进位，触发"每小时结算" |
| 天 | 1-7 | 每满 24 小时进位，触发"每日结算" |
| 周 | 累计 | 每满 7 天进位，触发"每周结算"（以 rentWeek 计数） |

时间**不会自动流逝**，而是由玩家的各种行为（打工、聊天、学习、休息、探索等）消耗对应分钟数来推进。

---

## 二、时段划分

一天被划分为 **7 个时段**，影响 NPC 出没、事件触发、环境描述等：

| 时段名 | 时间范围 | 典型场景 |
|--------|---------|---------|
| 清晨 | 05:00 - 08:00 | 早起活动 |
| 上午 | 08:00 - 12:00 | 打工、学习、NPC 白天活动 |
| 中午 | 12:00 - 14:00 | 午休、用餐 |
| 下午 | 14:00 - 17:00 | 自由活动、NPC 互动 |
| 傍晚 | 17:00 - 19:00 | 过渡时段 |
| 晚上 | 19:00 - 22:00 | 夜间活动、同居角色归家 |
| 深夜 | 22:00 - 05:00 | 高疲劳惩罚时段 |

---

## 三、每小时结算机制

每当时间推进跨越整点时，自动执行以下生存属性变化：

### 3.1 饱食度（satiety）

- 每小时自然衰减 **-2 点**
- 最低降至 0
- 当饱食度 <= 10 时，弹出警告："你饿得头晕眼花......赶紧吃点东西吧。"

### 3.2 疲劳度（fatigue）

- 正常时段：每小时增长 **+1 点**
- 深夜时段（23:00 - 05:00）：每小时增长 **+2 点**（熬夜惩罚）
- 最高升至 100
- 当疲劳度 >= 90 时，弹出警告："你已经困得站不稳了......该休息了。"

### 3.3 清洁度（cleanliness）

- 每小时自然衰减 **-1 点**（初始默认 90）
- 最低降至 0
- 打工、运动等行为会额外扣除（由具体系统处理）
- 当清洁度 <= 15 时，弹出警告："你浑身黏糊糊的......该洗个澡了。"

### 3.4 压力值（stress）

压力值受其他属性的极端状态影响，为复合增长机制：

| 条件 | 每小时压力增长 |
|------|--------------|
| 饱食度 <= 20（很饿） | +1 |
| 疲劳度 >= 70（很累） | +1 |
| 清洁度 <= 20（很脏） | +1 |

- 多个条件可同时生效，最多每小时 +3
- 最高升至 100

### 3.5 课程提醒

- 每小时检查社区大学是否有即将开始的课程，及时提醒玩家

## 四、每日结算机制（日变更）

当小时数满 24 进入新一天时，触发以下重置与联动：

### 4.1 日常状态重置

| 状态字段 | 重置值 | 说明 |
|---------|--------|------|
| catFedToday | false | 今日是否喂过猫 |
| catPettedToday | false | 今日是否撸过猫 |
| kDateAvailable | true | K 约会是否可用 |
| leiDeDateAvailable | true | 莱德约会是否可用 |
| townEventSeen | {} | 已触发的城镇事件清单 |
| townEventCount | 0 | 今日城镇事件计数 |
| dailyBuffs | {phys=0, magic=0, def=0} | 每日临时增益 |
| felixBreadToday | false | 今日是否从费利克斯处获得面包 |
| sparringToday | false | 今日是否已切磋 |
| townBattleToday | 0 | 今日城内战斗次数 |
| stallRevenue | 0 | 小摊今日收入 |

### 4.2 联动其他系统

日变更时依次通知以下子系统执行各自的每日逻辑：

1. **种植系统（FarmingSystem）**：作物每日生长一个阶段
2. **社区大学（UniversitySystem）**：重置每日上课次数
3. **家庭系统（HomeSystem）**：每日来访判定（如 K 的随机来访）与事件重置
4. **关键词聊天（KeywordSystem）**：重置每日已聊话题，允许新话题解锁

## 五、每周结算机制（周变更）

当天数满 7 天进入新一周时，触发以下逻辑：

### 5.1 房租结算

这是周结算中最核心的机制，流程如下：

1. **检查上周是否已缴租**：若 `rentPaidThisWeek` 为 false 且不是第一周，则累计欠租
2. **欠租累积**：`oweRent += rentDue`
3. **驱逐判定**：若 `oweRent >= rentDue * 2`（欠租达到两周以上），触发驱逐事件
   - 设置 `evicted = true`
   - 弹出通知："你因为欠租太多被赶出了家门！"
   - 记录日志

### 5.2 周状态重置

| 状态字段 | 重置值 | 说明 |
|---------|--------|------|
| rentPaidThisWeek | false | 本周是否已缴租 |
| rentWarningShown | false | 本周是否已显示催租提醒 |
| rentDueDate | 0 | 缴租截止日 |
| rentDue | 500（第2周起） | 每周应缴租金 |
| etiquetteTrainedThisWeek | false | 本周是否已进行礼仪训练 |
| banquetAttendedThisWeek | false | 本周是否已参加宴会 |
| oamelLoanUsed | false | 本周是否已向奥梅尔借钱 |

## 六、同居角色时间表

### 莱德（initialName）的作息

莱德在家的时间段：

| 时间范围 | 状态 |
|---------|------|
| 19:00 - 06:00 | 在家（晚归/睡觉） |
| 11:00 - 13:00 | 在家（午休） |
| 其余时间 | 外出 |

前提条件：`initialNameAtHome` 必须为 true（莱德已被邀请同住）。

### 莱德的状态描述（按时间段）

| 时间 | 描述概要 |
|------|---------|
| 22:00 - 06:00 | 已入睡。根据是否同床有不同描述（同床：侧躺在床上；否则：蜷缩在沙发上） |
| 21:00 - 22:00 | 在床头或沙发上借光阅读魔法书，非常专注 |
| 其他在家时段 | 在桌边研读魔法书籍和论文草稿，眉头微蹙，笔耕不辍 |

环境细节会根据游戏道具动态变化（如蜡烛数量影响照明描述）。

## 七、与其他系统的集成关系

```
TimeSystem（核心时钟）
    |
    |-- 每小时 --> 生存属性衰减（饱食/疲劳/清洁/压力）
    |           --> 社区大学课程提醒
    |
    |-- 每日 ---> 种植系统（作物生长）
    |           --> 社区大学（上课次数重置）
    |           --> 家庭系统（来访判定）
    |           --> 关键词聊天（话题重置）
    |           --> 城镇生活（事件计数重置）
    |           --> 战斗系统（切磋/治安次数重置）
    |
    |-- 每周 ---> 房租结算与驱逐判定
    |           --> 周限行为重置（礼仪/宴会/借款）
    |
    |-- 时段查询 --> NPC 出没调度
    |             --> 事件触发条件
    |             --> 环境氛围描述
    |             --> 同居角色状态
```

## 八、设计要点总结

1. **时间由行为驱动**：玩家不会"等待"时间流逝，而是通过主动选择行为推进时间
2. **生存压力循环**：饱食、疲劳、清洁三项属性持续衰减，迫使玩家合理安排日程
3. **压力为复合指标**：不直接衰减，而是在其他属性恶化时被动增长，形成连锁反应
4. **深夜惩罚**：熬夜（23:00-05:00）疲劳增速翻倍，鼓励玩家维持正常作息
5. **周期性经济压力**：每周 500 金币的房租创造持续的赚钱动力，欠租两周即被驱逐
6. **松散耦合设计**：TimeSystem 通过 pcall + require 通知子系统，各系统独立响应日/周变更
