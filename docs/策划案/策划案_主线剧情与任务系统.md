## 1. 系统概述

### 1.1 架构

主线剧情由 `mqStage` 变量驱动，贯穿三个章节共 20 个阶段（0→20）。每个章节由独立模块实现：

| 文件 | 章节 | 阶段范围 | 主题 |
|------|------|---------|------|
| `MainQuest.lua` | 第一章 | mqStage 0-5 | 被囚之人 — 发现与营救 |
| `MainQuestCh2.lua` | 第二章 | mqStage 6-12 | 阶级裂痕 — 矛盾与选择 |
| `MainQuestCh3.lua` | 第三章 | mqStage 13-20 | 真相之光 — 揭示与抉择 |

辅助系统：

| 文件 | 功能 |
|------|------|
| `SideQuests.lua` | 4 条支线任务 |
| `RandomEvents.lua` | DOL 风格随机事件池 |

### 1.2 核心叙事结构

```
序幕（日常生活）
  ↓ day >= 4
第一章：发现传闻 → 调查（4源） → 潜入营救 → 莱德觉醒
  ↓ day >= mqSettledDay + 5
第二章：阶级冲突 → 三路分歧 → 暗教会浮现 → 乌列尔登场
  ↓ mqStage == 12
第三章：暴动 → 真相揭示（父亲/莱德/K/乌列尔）→ 5 个结局
```

### 1.3 章节触发条件

| 章节 | 触发条件 | 触发地点 |
|------|---------|---------|
| 第一章 | `mqStage == 0` 且 `day >= 4` | 商业区 |
| 第二章 | `mqStage == 5` 且 `day >= mqSettledDay + 5` | 十字路口 |
| 第三章 | `mqStage == 12` | 十字路口 |

### 1.4 任务提示系统

每个阶段通过 `getQuestHint()` 返回当前任务提示，显示在任务面板中。格式为 `{text, detail}` 表，引导玩家了解当前目标与下一步方向。

## 2. 第一章：被囚之人

**阶段范围**: mqStage 0 → 5  
**主题**: 在港口城市的日常生活中发现阴谋，勇敢踏出营救之路

### 2.1 阶段流程

```
Stage 0: 街头传闻
  玩家在商业区听到魏德曼家族囚禁少年的传闻
  → mqStage = 1

Stage 1: 追查真相
  向 4 个信息源打听（需完成 ≥ 2 条）
  → mqInvestSources >= 2 → mqStage = 2

Stage 2: 决定营救 → 潜入庄园
  选择 4 种潜入方式之一
  → mqStage = 3

Stage 3: 寻找地下室 → 开锁
  5 种开锁方式
  → 找到莱德 → mqStage = 4

Stage 4: 遭遇奥梅尔 → 逃离
  3 种应对选择
  → 莱德释放光属性力量 → 逃离 → mqStage = 5

Stage 5: K的酒馆 → 新的清晨
  安置莱德于酒馆
  → 第一章结束
```

### 2.2 调查线索系统（Stage 1）

需从 4 条线索路线中完成至少 2 条（`mqInvestSources >= 2`）：

| 线索源 | 位置 | 前置条件 | 获得信息 | 附加效果 |
|--------|------|---------|---------|---------|
| 辛奇（酒馆老板） | 港口 | `npcSinchi >= 15` | 奥梅尔家秘密地下室位置 | mqKnowsSinchiClue = true |
| 克丽丝（教堂修女） | 教堂 | `npcClarice >= 15` | 少年身份为瓦勒姆家族后裔 | mqKnowsClariceClue = true |
| 黑胡子（港口头目） | 港口 | `npcBlackbeard >= 15` | 守卫排班表 + 暗门位置 | mqKnowsSecretDoor = true |
| 知识推理 | 任意 | 已收集「礼仪知识」或「历史知识」关键词 | 瓦勒姆家徽含义 | mqKnowsSecretDoor = true |

> **设计意图**: 多元化信息收集鼓励玩家在前期与不同 NPC 建立关系。好感度 15 的门槛约等于 3-5 次闲聊互动。

### 2.3 潜入方式（Stage 2）

| 方式 | 条件 | 警戒增量 | 说明 |
|------|------|---------|------|
| 正面混入 | `ML >= 5` 或持有通行证 | +0 | 最优选择，魅力或道具加持 |
| 翻墙潜入 | `JQ >= 5` 或 `NL >= 4` | +1 | 技巧型路线 |
| 暗门进入 | `mqKnowsSecretDoor == true` | +0 | 需要完成黑胡子或知识推理线索 |
| 蹲守等待 | 无条件（默认） | +2 | 保底选项，代价最高 |

### 2.4 开锁方式（Stage 3）

| 方式 | 条件 | 警戒增量 | 特殊效果 |
|------|------|---------|---------|
| 撬锁 | `JQ >= 7` 或持有铁片 | +0 | — |
| 找钥匙 | `LG >= 5` | +1 | — |
| 踹门 | `LL >= 6` | +3 | 噪音最大 |
| 光属性破锁 | `GSX >= 8` | +0 | 触发特殊剧情（莱德感应到光属性） |
| 仔细搜索 | 无条件（默认） | +1 | — |

### 2.5 警戒等级系统

`mqAlertLevel` 从 0 开始累计，影响 Stage 4 逃离的难度：

| 警戒等级 | 逃离场景 |
|---------|---------|
| 0-1（低） | 顺利逃出庄园，无追兵 |
| 2-3（中） | 遭遇追兵，但成功逃脱 |
| 4+（高） | 被包围，莱德被迫释放光属性力量，力量暴走 |

### 2.6 遭遇奥梅尔（Stage 4）

三种应对选择：

| 选择 | 描述 | 效果 |
|------|------|------|
| 挡在莱德身前 | 勇敢路线 | YG +2，对话分支偏向正义 |
| 尝试说服奥梅尔 | 外交路线 | ML 检定，成功可降低冲突 |
| 拉着莱德就跑 | 务实路线 | 直接进入逃离阶段 |

### 2.7 第一章奖励汇总

| 节点 | 奖励 |
|------|------|
| 完成第一章 | 莱德好感 +30 |
| 完成第一章 | K好感 +10 |
| 完成第一章 | 勇气(YG) +2 |
| 调查线索（各线） | 对应 NPC 好感提升（隐含） |
| 光属性破锁 | 触发莱德特殊感应剧情 |

## 3. 第二章：阶级裂痕

**阶段范围**: mqStage 6 → 12  
**主题**: 城市的阶级矛盾激化，玩家选择立场，暗教会浮出水面

### 3.1 阶段流程

```
Stage 6: 阶级矛盾
  目睹贵族马车撞倒老人 → 3 种回应

Stage 7: 外套回忆
  莱德回忆被囚往事 → 核心情感场景 → 3 种回应（影响好感）

Stage 8: 三路分歧
  选择解决路线：黑帮 / 调停 / 贵族

Stage 9: 路线执行
  各路线 3 个子任务（mq2RouteProgress 0→3）

Stage 10: 暗教会
  三条路线汇聚 → 发现暗教会阴谋

Stage 11: 乌列尔登场
  神秘青年乌列尔出现 → 3 种对话选择

Stage 12: 暴风前夜
  第二章结束 → 暴风将至的预感
```

### 3.2 阶级矛盾事件（Stage 6）

| 选择 | 描述 | 属性奖励 |
|------|------|---------|
| 帮助老人 | 扶起老人、替他说话 | YG(勇气) +2 |
| 斥责车夫 | 当众指责贵族随从 | YG(勇气) +3 |
| 观察人群 | 冷静分析局势 | LG(灵感) +2 |

### 3.3 外套回忆（Stage 7）— 核心情感场景

莱德向玩家讲述在庄园被囚的记忆。这件外套是他唯一的私人物品。

| 回应选择 | 好感变化 | 情感倾向 |
|---------|---------|---------|
| 道歉（"对不起，我来晚了"） | 莱德好感 +15 | 共情、歉疚 |
| 回避（转移话题） | 莱德好感 +5 | 不知所措 |
| 反问（"那你现在感觉怎样？"） | 莱德好感 +10 | 关心、理性 |

> **设计意图**: 这是玩家与莱德关系的第一个关键转折点。道歉选项给出最高好感，但三种选择都是合理的情感反应。

### 3.4 三路分歧系统（Stage 8-9）

选择路线后，`mq2Route` 被设为 1/2/3，锁定后续子任务。

#### 黑帮路线（mq2Route = 1）

联合地下势力对抗贵族压迫。

| 子任务 | 地点 | 内容 | 奖励 |
|--------|------|------|------|
| 送情报 | 花街 | 将消息传递给黑胡子 | gangTrust +2 |
| 安抚商户 | 商业区 | 安抚受骚扰的商户 | gangTrust +2 |
| 传话教堂 | 教堂 | 联络教堂配合行动 | gangTrust +2 |

#### 调停路线（mq2Route = 2）

居中调解各方矛盾，寻求和平解决。

| 子任务 | 地点 | 内容 | 奖励 |
|--------|------|------|------|
| 送信 | 花街 | 传递和谈意向给辛奇 | mediateTrust +2 |
| 说服奥梅尔 | 主城区 | 说服奥梅尔接受谈判 | mediateTrust +2 |
| 安排场地 | 教堂 | 在教堂安排谈判场所 | mediateTrust +2 |

#### 贵族路线（mq2Route = 3）

从贵族内部调查真相，揭示更深层的阴谋。

| 子任务 | 地点 | 内容 | 奖励 |
|--------|------|------|------|
| 查供货商 | 商业区 | 调查供货商记录 | nobleDebt +1 |
| 查教堂 | 教堂 | 调查教堂捐款记录 | nobleDebt +1 |
| 查父亲 | 主城区 | 调查玩家父亲的交易 | nobleDebt +1 |

> **设计意图**: 三条路线提供不同视角观察同一社会矛盾，最终在 Stage 10 汇聚。贵族路线比其他路线更早暗示父亲的秘密。

### 3.5 暗教会事件（Stage 10）

三条路线汇合点。无论选择哪条路线，都会发现暗教会在幕后操纵阶级矛盾。

| 回应 | 描述 | 效果 |
|------|------|------|
| 对峙 | 当面质问暗教会成员 | 获得更多信息，但增加危险 |
| 沉默 | 暗中观察 | 安全但信息较少 |
| 逃跑 | 立刻撤退 | 最安全选择 |

核心揭示：瓦勒姆家族血脉与暗教会阴谋直接相关。

### 3.6 乌列尔登场（Stage 11）

| 对话选择 | 乌列尔好感 | 附赠 |
|---------|-----------|------|
| 选项 1（友好） | +10 | 山核桃饼干（饱食度 +20） |
| 选项 2（戒备） | +8 | 山核桃饼干（饱食度 +20） |
| 选项 3（好奇） | +12 | 山核桃饼干（饱食度 +20） |

### 3.7 暴风前夜（Stage 12）

第二章结幕。所有路线的信息汇聚，暗示更大的风暴即将来临。

| 奖励 | 数值 |
|------|------|
| 莱德好感 | +5 |
| K好感 | +5 |

## 4. 第三章：真相之光

**阶段范围**: mqStage 13 → 20  
**主题**: 世界观核心秘密逐一揭开，玩家面临终极抉择

### 4.1 阶段流程

```
Stage 13: 暴动爆发
  城中三处动乱 → 选择前往区域

Stage 14: 父亲的交易
  发现信件 → 太阳神交易真相

Stage 15: 莱德封印
  莱德 = 第六代太阳核心守护者

Stage 16: K的真面目
  K = 第七代守护天使

Stage 17: 乌列尔抉择
  乌列尔的情感正被债务吞噬

Stage 18: 太阳神殿
  进入神殿 → 暗教会对决 → 乌列尔救场

Stage 19: 最终抉择
  5 个结局选择

Stage 20: 尾声
  结局演出
```

### 4.2 暴动爆发（Stage 13）

| 选择区域 | 效果 | 属性奖励 |
|---------|------|---------|
| 前往商业区 | 帮助商户抵抗暴动 | 特定属性 +3 |
| 前往教堂 | 帮助克丽丝保护难民 | 特定属性 +3 |
| 前往花街 | 帮助花街居民自保 | 特定属性 +3 |

### 4.3 世界观核心揭示

#### Stage 14：父亲的交易

> 玩家父亲曾与太阳神立下契约：借用太阳之力让家族兴旺，代价是**长子的全部情感**。

- 发现方式：找到父亲的密封信件
- 玩家反应选择影响后续走向
- 连接第二章贵族路线中的伏笔

#### Stage 15：莱德封印

> 莱德是**第六代太阳核心守护者**。玩家在 8 岁时意外打破了莱德的封印，这就是第一章中莱德被囚禁的原因。

- 解释了魏德曼家族为何囚禁莱德
- 解释了莱德拥有光属性力量的原因
- 玩家与莱德的命运从童年就已交织

#### Stage 16：K的真面目

> K 是**第七代守护天使**。她一直以酒馆老板的身份守护着莱德和玩家。

- 解释了核心归还机制与代价
- K 知道所有真相但选择等待玩家自己发现
- 核心一旦归还，宿主将失去全部超自然能力

#### Stage 17：乌列尔的情感债务

> 乌列尔表面的冷漠**不是性格**，而是他父亲的债务利息正在吞噬他的情感。

- 三个对话选择影响乌列尔好感度：
  - 选项 1：乌列尔好感 +5
  - 选项 2：乌列尔好感 +3
  - 选项 3：乌列尔好感 +8
- 这一揭示将乌列尔从"神秘角色"转变为"需要拯救的人"

### 4.4 太阳神殿（Stage 18）

- 暗教会试图夺取太阳核心

## 6. 随机事件系统

**机制**: DOL 风格概率触发事件池  
**每日上限**: 5 次（`townEventCount`）  
**状态追踪**: `townEventSeen` 防止同一事件重复触发

### 6.1 生存状态触发事件

当玩家的生存数值达到危险阈值时，自动触发对应事件：

| 类型 | 触发阈值 | 概率 | 危急阈值 | 效果 |
|------|---------|------|---------|------|
| 饥饿 | 饱食度 ≤ 25 | 40% | ≤ 10 | 眩晕、体力下降、可能晕倒 |
| 疲劳 | 疲劳 ≥ 70 | 35% | ≥ 90 | 注意力下降、可能晕倒 |
| 压力 | 压力 ≥ 60 | 30% | ≥ 85 | 情绪波动、判断失误 |

### 6.2 地点事件池

#### 十字路口

| 事件 | 概率 | 检定 | 成功 | 失败 |
|------|------|------|------|------|
| 扒手事件 | 15% | JQ(技巧) | 抓住扒手获奖励 | 被偷金币 |
| 卖花老人 | 20% | 无 | 购买鲜花 | — |

### 6.3 属性检定公式

```
成功率 = min(95, max(5, 基础值 + 属性值 × 乘数))
→ 无论属性多高/多低，成功率都限制在 5% ~ 95%
→ 然后进行随机 roll 判定
```

## 7. 五大结局详解

### 结局 1：打破壁垒

| 项目 | 内容 |
|------|------|
| **选择** | 玩家亲自归还太阳核心 |
| **代价** | 玩家失去全部超自然力量，成为普通人 |
| **收获** | 乌列尔恢复情感；太阳核心回归平衡 |
| **基调** | 牺牲与重生 |

### 结局 2：革命

| 项目 | 内容 |
|------|------|
| **选择** | 击碎太阳核心 |
| **效果** | 太阳之力分散给所有人 |
| **结果** | 没有神，没有天使，人人平等 |
| **基调** | 激进变革 |

### 结局 3：改良

| 项目 | 内容 |
|------|------|
| **选择** | 让乌列尔归还核心 |
| **代价** | 乌列尔失去全部力量，变为普通人 |
| **收获** | 乌列尔恢复情感，流下第一滴眼泪 |
| **基调** | 最具情感冲击力的结局 |

### 结局 4：牺牲

| 项目 | 内容 |
|------|------|
| **选择** | 请求莱德重新封印太阳核心 |
| **分支条件** | 莱德好感度（`initialNameAffection`） |

| 好感度 | 结果 |
|--------|------|
| ≥ 60 | 莱德保持清醒，作为有意识的守护者永远守护核心 |
| < 60 | 莱德进入永久沉睡，再无醒来之日 |

> **设计意图**: 好感度的积累不仅是情感投入的象征，更直接决定了莱德在这个结局中的命运。

### 结局 5：隐藏结局

| 项目 | 内容 |
|------|------|
| **前置条件** | 发现「祭台秘密」— 第七个凹槽可容纳 K 的光环 |
| **选择** | 说服所有阵营和解 |
| **结果** | 太阳核心自行稳定，无需任何牺牲 |
| **基调** | 最理想的结局 — 皆大欢喜 |

### 结局对比总览

| 结局 | 牺牲者 | 世界影响 | 达成难度 |
|------|--------|---------|---------|
| 打破壁垒 | 玩家（失去力量） | 恢复平衡 | ★☆☆ |
| 革命 | 旧秩序 | 彻底变革 | ★☆☆ |
| 改良 | 乌列尔（失去力量） | 渐进改革 | ★★☆ |
| 牺牲 | 莱德（封印/沉睡） | 维持现状 | ★★☆ |
| 隐藏结局 | 无 | 完美和解 | ★★★ |
