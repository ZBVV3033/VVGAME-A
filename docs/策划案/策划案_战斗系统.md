## 1. 系统概述

回合制RPG战斗系统，嵌套在"渡劫森林"探索玩法中。玩家操控最多3人小队（主角+K+莱德），对抗石系怪物。战斗采用速度排序的回合制，支持技能分类、状态效果、形态切换等机制。

### 3.1 敌人模板

| 敌人 | HP | 力量 | 灵感 | 速度 | 防御 | 魔防 | 经验 | 金币 | 类型 |
|------|-----|------|------|------|------|------|------|------|------|

| 苔藓巨石 | 80 | 5 | 3 | 3 | 8 | 30% | 75 | 20 | 精英 |
| 石像鬼统领 | 150 | 6 | 4 | 5 | 10 | 30% | 250 | 100 | Boss |

### 3.2 敌人技能

| 技能 | 效果 |
|------|------|
| 冲撞/暗影球 | 普通攻击（取物理/魔法伤害中较高者） |
| 硬化 | 防御+2，力量+1，持续2回合 |
| 粉身碎骨 | 高伤害`(atkBase + 4*power - targetDef)`，自身防御-1 |
| 腐蚀气息 | 全体魔法伤害`10*(1-mdef)` + 腐烂2回合 |

### 3.3 敌人AI

- **技能循环**: 按预设顺序执行技能（如 attack→harden→attack→attack→smash）
- **紧急技能**: HP低于50%时触发一次（通常为粉身碎骨）
- **目标选择**: 攻击血量最低的玩家队员

## 4. 伤害公式

### 4.1 物理伤害
```
基础伤害 = atkBase + 系数 × (power + buff.power)
最终伤害 = max(1, 基础伤害 - enemyDef) × dmgMult × (1 + uniBonus.phys) × (1 + dailyPhys)
```

### 4.2 魔法伤害
```
基础伤害 = matkBase + 系数 × insight
最终伤害 = max(1, 基础伤害 × (1 - target.mdef)) × (1 + uniBonus.magic) × (1 + dailyMagic)
```

### 4.3 大学专业加成
- 战士学: 物理伤害百分比加成 (`uniCombatBonus_phys`)
- 魔法学: 魔法伤害百分比加成 (`uniCombatBonus_magic`)
- 神学: 魔法抗性加成 (`uniCombatBonus_mdef`)

### 4.4 商人每日Buff
- 物理加成 (`dailyBuffs.phys`)
- 魔法加成 (`dailyBuffs.magic`)
- 防御加成 (`dailyBuffs.def`)

## 5. 回合系统

### 5.1 行动顺序
按速度(speed)从高到低排序，速度相同则随机。

### 5.2 回合流程
1. 生成行动顺序（按速度排序）
2. 当前角色行动（玩家选择技能/敌人AI行动）
3. 推进到下一个存活角色
4. 一轮结束时执行被动效果（回血、buff衰减等）
5. 检查战斗结束条件

### 5.3 战斗结束
- **胜利**: 所有敌人HP≤0 → 分配经验/金币 → 升级检查
- **失败**: 所有队员HP≤0 → 重置到森林第1层，恢复50% HP/MP

## 6. 逃跑系统

```
逃跑率 = max(10%, min(85%, 40% + (avgPlayerSpeed - avgEnemySpeed) × 5% + tacticsLevel × 5%))
```

- Boss战不可逃跑
- 逃跑失败消耗当前角色回合
- 战术学知识每级+5%逃跑率

## 7. 升级系统

| 参数 | 说明 |
|------|------|
| 经验分配 | 所有存活队员获得等同经验 |
| 升级奖励 | 每级+1属性点，恢复50% HP/MP |
| 里程碑奖励 | Lv.5和Lv.10时 atkBase+3, matkBase+2 |
| 经验递增 | 每级所需经验 = 上一级 × 1.2 |
| 初始所需经验 | 450（Lv.10） |

## 8. 渡劫森林探索

### 8.1 结构

| 层数 | 敌人配置 | 说明 |
|------|----------|------|
| 1-2层 | 1-2个小石块 | 入门难度 |
| 3-4层 | 苔藓巨石（单独/+小石块） | 中等难度 |
| 5层 | 石像鬼统领（Boss） | 最终Boss |

### 8.2 遇敌机制
- 探索时有概率遇敌
- 无遇敌时40%概率触发随机事件

### 8.3 森林事件

| 事件 | 效果 |
|------|------|
| 神秘果树 | 选红色果实(力量+1)/蓝色果实(灵感+1)，一次性 |
| 森林温泉 | 全体恢复20%HP 或 最大HP+5 |
| 被袭女孩 | 战斗事件，胜利后获30-60金币+30%HP恢复 |

### 8.4 森林商人

在森林中随时可访问的商人系统，使用森林金币(gold)购买。

## 10. 数据持久化

战斗结束后通过 `saveCombatData()` 将战斗中的角色数据写回 `GameState` 持久存储。

**关键机制**: `stripTempBuffs()` 在保存前清除临时战斗buff对基础属性的污染：
- 守护姿态/硬撑的防御加成
- K附魔的属性加成
- 大学专业魔防加成

确保下次战斗开始时属性干净。
