## 1. 角色属性体系

### 1.1 五维基础属性

角色有 5 项基础属性，影响战斗、打工、社交等各系统的判定。

| 属性 | 缩写 | 初始值 | 说明 |
|------|------|--------|------|
| 力量 | LL | 1 | 影响物理伤害、搬运类工作 |
| 灵感 | LG | 1 | 影响魔法伤害、创意类判定 |
| 魅力 | ML | 3 | 影响社交、晚宴、服务员工作 |
| 耐力 | NL | 2 | 影响体力消耗、铁匠工作 |
| 技巧 | JQ | 1 | 影响暴击、手工类工作 |

**属性上限**: 0~999（通过 `GameState.modStat` 限制）

**提升途径**:
- 打工经验（对应职业提升对应属性）
- 阅读书籍
- 大学课程
- 森林果树事件
- NPC好感度升级（莱德/K升级时五维各+1）
- 生活等级升级（获得属性点）

### 1.2 个性属性

影响剧情分支和 NPC 反应。

| 属性 | 缩写 | 初始值 | 说明 |
|------|------|--------|------|
| 勇敢 | YG | 0 | 影响正面对抗类剧情选择 |
| 冷静 | LJ | 0 | 影响理性分析类剧情选择 |
| 暴躁 | BZ | 0 | 影响冲动行为后果 |
| 智力 | ZL | 0 | 影响推理、学习效率 |

### 1.3 魔法属性

影响战斗技能效果和部分剧情。

| 属性 | 缩写 | 初始值 | 说明 |
|------|------|--------|------|
| 暗属性 | ASX | 1 | 暗系技能加成 |
| 光属性 | GSX | 5 | 光系技能加成（圣光斩伤害加成=GSX×1.5） |
| 木属性 | MSY | 1 | 自然系技能加成 |

### 1.4 声望与道德

| 属性 | 初始值 | 说明 |
|------|--------|------|
| 声望 (reputation) | 0 | 完成正面事件增加，影响部分NPC对话和结局 |
| 邪恶 (evilness) | 0 | 作恶行为增加，影响暗线剧情和结局 |

## 2. 生存属性系统

角色有 4 项需要持续维护的生存属性，会随时间自然衰减。

| 属性 | 初始值 | 范围 | 衰减规则 | 影响 |
|------|--------|------|----------|------|
| 饱食度 (satiety) | 80 | 0~100 | 每小时-2~3 | 低于30影响工作效率 |
| 疲劳 (fatigue) | 0 | 0~100 | 活动增加，睡眠减少 | 高于70影响行动 |
| 压力 (stress) | 0 | 0~100 | 事件增加，休闲减少 | 高于70影响社交 |
| 清洁度 (cleanliness) | 90 | 0~100 | 每小时-1~2 | 低于50影响NPC好感 |

**恢复方式**:
- **饱食度**: 烹饪吃饭、购买食物
- **疲劳**: 在卧室睡觉
- **压力**: 阅读、散步、泡温泉、和NPC聊天
- **清洁度**: 在浴室洗澡

## 3. 货币系统

游戏有两套独立货币：

| 货币 | 变量 | 说明 |
|------|------|------|
| 金币 (money) | S.money | 主货币，用于日常消费、房租、购物 |
| 森林金币 (gold) | S.gold | 战斗货币，仅在渡劫森林获取，用于森林商人 |

**金币收入来源**:
- 打工工资（受职业等级、梅菲斯加成、奥梅尔技能影响）
- 晚宴小费
- 小摊收入（烹饪系统）
- 战斗胜利奖励（进入 gold）

**金币支出**:
- 房租（每周100起）
- 购买食材/种子
- 购买书籍

## 4. 房租系统

| 参数 | 值 | 说明 |
|------|-----|------|
| 初始房租 | 100/周 | 每周一结算 |
| 支付期限 | 每周 | 逾期累计欠款 |
| 驱逐条件 | 累计欠租 | 触发被驱逐事件 |

**相关变量**:
- `rentPaidThisWeek`: 本周是否已付
- `rentWeek`: 当前周数
- `rentDue`: 当前房租金额
- `oweRent`: 欠租金额
- `evicted`: 是否被驱逐

## 6. 知识系统

通过阅读书籍和大学课程提升，影响工作效率、战斗和剧情选项。

| 知识 | 对应书籍 | 初始等级 | 效果 |
|------|----------|----------|------|
| 礼仪 (manner) | 礼仪手册 | 1 | 晚宴表现、梅菲斯好感 |
| 历史 (history) | 历史书 | 1 | 剧情选项、贵族对话 |
| 神学 (theology) | 圣典基础教义 | 0 | 教堂工作、光魔法加成 |
| 植物学 (botany) | 植物学入门 | 0 | 种植产量、采集效率 |
| 修理 (repair) | 机械修理入门 | 0 | 铁匠工作效率 |
| 战术 (tactics) | 战术教材 | 0 | 逃跑成功率+5%/级 |
| 魔法理论 (magicTheory) | 魔法教材 | 0 | 魔法伤害加成 |
| 烹饪理论 (cookTheory) | 烹饪教材 | 0 | 烹饪成功率 |

**书籍获取**: NPC赠送（克丽丝赠神学、麦拿拿赠修理）、书店购买

**阅读机制**: 每本书有 `readCount`，首次阅读有额外奖励（`firstReward`）

## 7. 生活等级系统

| 参数 | 说明 |
|------|------|
| lifeLevel | 当前生活等级（初始1） |
| lifeExp | 当前经验值 |
| attrPoints | 可分配属性点 |

**经验来源**: 打工、做饭、完成任务等日常活动
**升级奖励**: 每级获得属性点，可自由分配到五维属性

## 8. 时间系统

### 8.1 时间参数

| 参数 | 初始值 | 说明 |
|------|--------|------|
| 年 (year) | 499 | 游戏起始年份 |
| 月 (month) | 1 | 1-12月 |
| 日 (day) | 1 | 每月天数 |
| 时 (hour) | 8 | 0-23小时 |
| 分 (minute) | 0 | 0-59分钟 |

### 8.2 时间消耗

| 活动 | 消耗时间 |
|------|----------|
| 打工 | 2-3小时 |
| 做饭 | 1小时 |
| 阅读 | 1小时 |
| 森林探索 | 30分钟/层 |
| 上课 | 1-2小时 |
| 约会 | 2小时 |
| 睡觉 | 到次日8点 |

### 8.3 星期系统

以 `(day-1) % 7 + 1` 计算星期（周一~周日），影响：
- 晚宴（每周一次）
- 房租结算（每周）
- 大学课程安排

## 9. 背包与物品

### 9.1 食材背包 (ingredients)

格式: `{ name = count }`，通过采集、购买获得，用于烹饪。

### 9.2 种子背包 (farmSeeds)

格式: `{ name = count }`，通过购买获得，用于种植。

### 9.3 采集物品 (forageItems)

格式: `{ ["野莓"] = 3, ["薄荷草"] = 1 }`，在森林采集获得。

### 9.4 家具 (furniture)

解锁式收集，通过NPC好感赠送获得：

| 家具 | 赠送者 | 解锁条件 |
|------|--------|----------|
| 咖啡机 | 辛奇（酒馆老板） | 好感等级1 |
| 圣典 | 克丽丝（修女） | 好感等级1 |
| 训练铁人 | 麦拿拿（矮人铁匠） | 好感等级1 |
| 小海鸥装饰 | 黑胡子（港口头目） | 好感等级1 |

## 10. 通知与日志系统

### 10.1 通知队列 (notifications)

格式: `{ text = "消息", time = 3.0 }`
- 显示3秒后自动消失
- 用于好感升级、获得物品等即时反馈

### 10.2 约会日志 (dateLogs)

最多保留50条，记录: 日期、人物、类型、内容

### 10.3 最近动态 (recentEvents)

最多保留5条，记录: 日期、时间、事件描述

## 11. 状态变量索引

### 核心属性 (12个)
`LL`, `LG`, `ML`, `NL`, `JQ`, `YG`, `LJ`, `BZ`, `ZL`, `ASX`, `GSX`, `MSY`

### 生存属性 (4个)
`satiety`, `fatigue`, `stress`, `cleanliness`

### 货币 (2个)
`money`, `gold`

### 时间 (5个)
`year`, `month`, `day`, `hour`, `minute`

### 社交 (50+个)
莱德/K/奥梅尔/梅菲斯/乌列尔/黑帮少主 × (好感/等级/互动标记)
次要NPC × 18人 × (好感/是否见面)

### 战斗 (30+个)
playerCombat/kCombat/initialNameCombat 各含 15+ 子属性

### 职业 (20+个)
5个职业 × (经验/等级/工资) + 解锁标记

### 主线任务 (30+个)
mqStage + 第二章/第三章各 10+ 标记变量

### 知识 (16+个)
8个知识领域 × (经验/等级)

### 总计: 约 400+ 状态变量
