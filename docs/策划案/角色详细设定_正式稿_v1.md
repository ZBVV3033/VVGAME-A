## 一、莱昂哈特·瓦勒姆（Leonhart Vallem）

### 1.1 基础档案


| 项目  | 内容                                                                                                                                                                                                                  |

| 身份  | 瓦勒姆家独子；月神诅咒下的「天赋之子」；边境军校学生                                                                                                                                                                                          |

| 称呼  | **入校显示名** 由玩家开局 **自定义** 或 **默认「莱昂哈特·瓦勒姆」**（简称策略见程序）；昵称 **默认「莱昂」**。不熟者多 **姓氏/爵位**（**「瓦勒姆同学」** 等）；**密友、恋人** 用 **名/昵称**，规则见 **§1.8**。**长期跳级、在校时间短**，**同级里常「脸生」**；**非深交圈** 对其 **教名/日常用名** 仍可 **不熟**，自定义显示名在剧情上 **可成立**。 |


### 1.2 外貌与辨识度

- **发色/瞳色**：**金发、赤瞳**（红瞳；与日系王族「绿瞳眷顾」形成视觉对照）。
- **体态**：偏苍白；身量中等偏瘦、有薄肌；比同龄人显小一号。**13 岁时身高约 162cm**（阿斯特 16 岁约 **170cm**）。
- **诅咒外显**：眼下易有淡青、偶发手抖或耳鸣（Demo 轻量演出即可）；整体偏**忧郁、破碎感**。
- **气质**：表面**面无表情**、安静（家里劝出来的礼貌妥协）；熟悉后会略松懈。**不爱无效社交**，更愿 **读书、练魔法、军团习武** 胜过「为应酬出门」；但 **并非无社交**——**绘画圈、写生/冒险同伴、部分中低贵族** 里有 **实在交情**。**8 岁起** 已能 **自控、不再随便失控**（幼时严管至此结束）；**多次跳级** 使他在普通学校里 **像挂学籍、只考试**，**同学难记住他长什么样**。他 **任性**，却 **懂察言观色**、也 **肯服从社会规则**——**学一套「普通人怎么接话、怎么站队」对他不难**；在 **公众场合**，尤其 **身份可能被读出** 时，会 **努力把事办圆**，守住 **瓦勒姆家的从容与体面**。**没人知道他是谁** 时，可以 **松一档**（仍可有底线，除非剧情要他绷脸或摆烂）。他 **嘴并不懒**，**浅聊** 才懒：**不熟的人** 看他像 **不接茬** 或 **人机**，有时其实是 **懒得给无聊场面贴金**；真开口时，火力见下条 **§1.3**。

### 1.3 性格与口吻

- **表层**：话可能**很多**、不怎么礼貌，**像黑猫一样高傲**、挑剔、喜怒无常；不熟则懒得多说；**效率主义**。  
- **体面开关（公众 vs 匿名）**：**任性** 与 **会演** **并存**。需要 **撑家族门面** 时，他能 **读空气、走流程、把场面撑住**；**身份隐去** 或 **判定为无效场合** 时，才更常 **省话、省笑、省客气**。  
- **嘴上分寸（非物理的「攻击」）**：**喜欢偶尔攻击别人**——对 **不熟 / 场面人** 多用 **婉转阴阳**（敬语、客气里 **夹刺**，体面不落把柄）；对 **熟人、信得过的人** 则 **直球怼、损友式拆台**。熟人侧可写成 **炸毛小猫对着人哈气**：**气人，但可爱**。**独处、日记、VoiceOverlay** 里可偶用 **抽象一点的自嘲**，**顺手讽刺自己或世态**（仍在 **高等语域** 里，**忌** 变市井骂街）。**公众撑场面** 与 **私下嘴毒** **不矛盾**：前者是 **任务**，后者是他给 **无聊收的手续费**。  
- **里层**：对极少数信任对象（现为阿斯特，可扩至弗里茨）**缓慢打开**；对「被当武器使」敏感。  
- **内心多面（勿写扁）**：**同一人物**里并存 **(1) 搞笑、带刺的乐观**（尤其独处或对阿斯特：冷幽默、错位类比、把惨事变段子）**(2) 冷静与长沉默**（把话咽回去、用眼睛先量一遍场面）**(3) 焦躁时的刻薄嘴快**（诅咒/名声/被围观压力下）。**长线剧情**勿只留其中一面。  
- **文学与艺术底色**：长期 **散文、诗歌、史传与理论书** 杂读；**自己绘画**（速写、默写轮廓、明暗分块）——观察世界时常带 **构图习惯**，内心独白可偶用 **长短句节奏** 与 **意象**；**重场**（高压、失控余波、仪式性场合等）**氛围到位时** 允许 **意象递进或金句式收束**，**忌** 平淡段 **无铺垫堆砌**（对表 `主角莱昂哈特_口吻与内心戏规范` **§5**）。**与阿斯特对照**：阿斯特的文学性更 **外放、舞台化**；莱昂更 **内向、机锋、克制**。  
- **语域（高等贵族 · 洒脱不下沉）**：出身决定他 **懂措辞、懂分寸**，即使 **厌恶表演** 也难完全 **「土味化」**；**洒脱** 体现为 **懒得多捧场、敢自嘲、敢拒绝**，而非 **刻意粗鄙** 或 **装傻**。**经济狼狈** 时可 **嘴硬、算账、硬撑**，但 **不必写成街头混混**（除非剧情明确 **伪装身份**）。  
- **对话习惯**：在 **军校**（脸生 + 流言 + 他常 **选择省力**）里，旁人易觉得他 **不接茬**；偶被误读为 **人机**——实为 **厌恶无效寒暄 + 诅咒压力 + 有时懒得演** 叠在一起（**≠** 学不会普通人规则，**≠** 没有朋友、从不外出）。一旦他 **决定开口**，往往带 **阴阳或直球**（见上条），与 **误读** 要 **分开写**。具体选项与内心声部 **对表**：`军校工会模拟器_主角莱昂哈特_口吻与内心戏规范_v1.md`。

**性格碎片 vs「完整的人」（叙事口径）**  

- 游戏中 **不同内心声部、性格向对白、选项气质**（如诅咒系统 **五声部** 等）是 **同一人身上的多棱面**，**不是** 把莱昂拆成若干「切片人格」。**立体的人** 本就可以 **搞笑与冷感同在、刻薄与脆弱同箱**；文案 **一次一场戏** 只 **擦亮其中几片** 即可。  
- **正式版** 可 **增加** 更多 **声部 / 叙事标签 / 条件解锁的内心句式**；亦可尝试 **高好感对象对莱昂的「沾染」**——语汇、比喻习惯、口头禅、看人的角度 **被长期相处塑形**（**传染** 是比喻：**不是夺舍**，是亲密关系里常见的模仿与应验）。Demo **可不实装**，本句作 **立项口径**。

**创作冲动：自幼读「A」与写作尝试（作者侧 · 可对玩家渐进揭示）**  

- 莱昂 **很小时就是笔名「A」的读者**：**第一部** 为 **阿斯特母亲** 所赠；此后 **「A」每有新作，夫人仍会送一册到瓦勒姆府**，莱昂 **回赠花卉小品、植物写生或夫人肖像**（礼节与真心兼有）。书中世界是其 **心灵的绿洲** 之一，**长期共鸣** 使他 **一度也想用文字造自己的世界**。书店/馆藏书目见 **§二·2.1 补充**。  
- **身份拼图**：**「A」即阿斯特** 可对莱昂 **渐进揭示**（幼时 **未对号、只对一半、心照不宣或晚确认** 等 **择线** 均可），与差分 Reveal **对表**；**不必** Demo 内落锤。  
- **自我认知**：他更多把 **绘画** 当 **主出口**——**更直观、更容易被一眼看见**；私下常自嘲 **「写得太长，没人看完」**（**反馈少、耐心被诅咒与日程挤压** 也是真的）。  
- **写作天赋**：**不必早下定论**——可保留 **伏笔**：未必 **没有才能**，更可能是 **缺编辑、缺读者、初稿冗长**；正式版可 **回收**（短文、便条、战报边注、回忆录文体、给某人的未寄信等），**与阿斯特对照**时不写 **「永远放弃笔」**。

### 1.4 背景与动机（玩家可见层）

- **诅咒**：高魔战天赋与代价共生。**8 岁前** 曾因 **易伤及他人** 而 **严管外出**（须 **族人或高阶治疗/稳定系法师** 陪同等，细则可随剧情一笔）。**8 岁后** 日常已能 **自控、不随便失控**；**入学后** 在 **压力、熬夜、诅咒读数攀高** 等条件下仍可能出现 **间歇性突破**（与 **D3 等强制剧情** 对表——写 **阈值与诱因**，勿写成「他从小天天失控」）。  
- **出行与爱好（入学前常态）**：**每周逛主城**、**偶尔远行**（**带护卫**），**写生画画**、**听音乐会、看戏剧**；在家则 **看书、练魔法、去军团学战斗**。  
- **社交口径**：**密友不多**，讨厌 **无效社交**；但在 **绘画、冒险/写生** 圈子里 **认识不少人**，与 **若干中低贵族** 关系 **不错**——与 **军校里脸生、不爱陪聊** **并存**。  
- **跳级与「记不住脸」**：**多次跳级** → 在普通学校里 **在校短、像挂学籍只考试** → **同学基本记不住他长什么样**；进军校后 **同级仍可能「只闻瓦勒姆、对不上人」**，利于 **流言与偏见先行**。  
- **战力与军校坐标**：**战斗与术式** 靠 **军团对练** 与 **法师院分部一对一** 打磨，**硬实力高于多数同龄人**。入学后同届多为 **大贵族 / 大资本家子弟**，**场面与同窗政治** 更熟，且 **尖子云集**；莱昂 **不再显得「碾压」**。**阿斯特** 的 **物理/近身作战** 更是 **年级前几** 的水平，形成 **对照**。  
- **圈子里的眼光**：**姓氏与诅咒传闻** 仍可先于 **真人印象**；偶被 **当谈资** 时，他更倾向 **抽身** 而非 **陪笑**（内心仍 **好胜**，见 §1.3）。  
- **文学与艺术**：**阅读与绘画** 是其 **心灵的绿洲**（与 §1.3 底色一致）；**出门写生/看戏** 与 **宅书** **不矛盾**。  
- **童年与阿斯特**：因必须出席的 **重要贵族聚会** 相识——两人都是 **在同场中易被冷落的「问题姓氏」孩子**，自然 **凑在一起**：**狂吃点心、溜去花园胡闹、一起闹脾气** 等。幼时阿斯特 **鼓励他坚持爱好**，夸 **画得好**，半开玩笑说 **「已经是大画家了」**。**阿斯特 12～16 岁服役那几年**，每年大约只回家 **三四次**（多在 **大典、戏剧演出** 等），见面窗口窄，但仍 **会找莱昂**、**催他别总缩在舒服圈里**——指的是 **军校/大场面里别躲**，**并非** 否定他已有 **画友、写生圈与中低贵族** 往来（见上条 **社交口径**）。**莱昂侧** 始终视对方为 **特别好的好兄弟**（与文首 **POV** 规则一致）。**「A」赠书与回礼** 见 **§1.3**。  
- **经济/生存**：贵族大学期**断供**可与 Demo 轻量提及；**首周**父亲可寄 **350 G** 生活费，**次周起**主要靠打工与工会周转（数字见《军校工会模拟器_Demo经济数值基准_v1》）。
- **主线动机**：寻找抑制或净化诅咒的路径；工会是凑资源与人手的手段。

他想当**自由画家**，偶尔设计喜欢的衣服；但他也会用这一份“艺术温柔”把自己的目的包得更漂亮。

**作者侧追加（暗线行动）**

- 他会**悄悄援助**被派上战场的法师院兄弟姐妹：送补给、改名单、替他们争取更安全的岗位、甚至在夜里为他们“补一次魔/上一次护符”。这些事在国家账目里不该存在，因此他必须用假名与伪装行动。

**作者侧追加（魔法能力与“创造魔法”）**

- **定位**：法师院体系内的**最年轻中级法师**之一；实战与救护两端都能上手。
- **属性覆盖**：几乎能使用**所有属性**魔法（稀有但可解释：皇家血脉 + 法师院培养 + 长期实操）。
- **最擅长**：
  - **皇室火魔法**：爆发、控温、焚烧净化与战场照明（可兼治疗辅助用途）。
  - **创造魔法**：用“含魔力的颜料”进行短时造物（偏艺术系/炼成系的变体）。**用少部分魔力画出的东西很快会消失**；若定期补充魔力，可维持更久。
- **彩色小精灵宠物（作者侧彩蛋）**：他画出一只彩色的小精灵当“宠物/使魔”。它需要定期补魔才能存在；平时是可爱的陪伴，战时可做短时侦查/传递小物件（Demo 可只做叙事/特效，不做复杂 AI）。
- **救护职责（执行官工作）**：他负责**寻找伤员与治疗伤员**；创造魔法也可用来临时制造一次性夹板、绷带、止血楔或简单工具。
