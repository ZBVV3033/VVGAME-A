# 工作系统策划案

---

## 一、系统概述

工作系统是游戏核心的日常经济与角色成长系统，涵盖**职业打工**、**读书学习**、**知识成长**、**生活等级**四大子系统。玩家通过打工赚取金币、积累职业经验、提升属性、解锁称号，同时触发丰富的叙事随机事件，推动与NPC之间的关系发展。

### 核心循环

```
打工/读书
  → 赚取金币 + 获得职业/知识经验
  → 升级（职业等级 / 知识等级 / 生活等级）
  → 属性提升 + 时薪增长 + 称号解锁
  → 解锁更高阶内容 / 通过属性检定获取更好的事件结局
```

### 系统依赖

| 外部系统 | 交互方式 |
|---------|---------|
| GameState | 读写全局状态（金币、属性、背包、日志等） |
| TimeSystem | 每次打工消耗60分钟，读书消耗30分钟 |
| NPCSystem | 打工事件影响NPC好感度；与莱德合作打工增加好感 |
| KeywordSystem | 打工时按职业收集剧情关键词（如 tavern_work、port_labor 等） |

## 二、职业总览

游戏共有 **5种** 可解锁职业，每种职业绑定一个主属性、拥有独立的经验和等级体系。

| 职业 | 名称 | 主属性 | 每级时薪增长 | 解锁变量 | 工作地点 | 老板/导师 |
|------|------|--------|------------|---------|---------|----------|
| waiter | 服务员 | 力量(LL) | +10 | unlockWaiter | 醉鹿酒馆 | 辛奇（酒馆老板）、K（调酒师） |
| cleric | 见习教士 | 灵感(LG) | +10 | unlockCleric | 太阳神教堂 | 克丽丝（修女） |
| blacksmith | 铁匠学徒 | 耐力(NL) | +10 | unlockBlacksmith | 麦拿拿铁匠铺 | 麦拿拿（矮人铁匠） |
| laborer | 港口杂工 | 力量(LL) | +10 | unlockLaborer | 港口码头 | 黑胡子（码头工头） |
| butler | 侍从 | 魅力(ML) | +15 | unlockButler | 罗斯巴特庄园 | 小奥（贵族少爷） |

### 同伴"莱德"系统

莱德（初始名同伴角色）拥有独立的打工经验/等级/时薪体系，可在 waiter、cleric、blacksmith、laborer 四种职业中与玩家协同打工（butler 除外）。合作打工时：

- 莱德获得独立经验，升级时力量+1、时薪+10
- 莱德赚取的工资一半分给玩家
- 莱德好感度+3
- 每个打工事件提供莱德专属分支选项与差分叙事文本

## 三、工作机制详解

### 3.1 基础打工流程

每次打工消耗 **1小时**（60分钟）游戏时间：

1. 计算实际工资（基础时薪 + 奥梅尔技能加成 + 梅菲斯工资加成）
2. 获得 **+20** 职业经验
3. 获得对应金币
4. 清洁度下降（体力劳动型 laborer/blacksmith 降8点，其他降5点）
5. 发放/穿上工作制服
6. 收集剧情关键词（30%概率额外收集"市集交易"关键词）
7. **75%概率** 触发一个随机叙事事件

### 3.2 工资计算

```
实际工资 = 基础时薪
         × (1 + 奥梅尔技能加成百分比)    -- 若奥梅尔技能激活
         + 梅菲斯工资加成                  -- 固定加成
```

### 3.3 首次打工奖励

玩家完成人生第一份工作时，获得政府就业补贴金 **+100金币**（一次性）。

## 六、打工随机事件系统

### 6.1 触发机制

- 每次打工 **75%概率** 触发一个随机事件
- 从当前职业的事件池中随机抽取
- 每个事件包含场景描述 + 2-3个选项
- 与莱德合作打工时，显示莱德差分描述文本和莱德专属选项

### 6.2 事件结构

每个事件包含：
- **desc**: 场景叙事描述（约200-400字的沉浸式叙事）
- **descLeiDe**: 莱德在场时的替代描述
- **choices**: 玩家可选的行动分支（2-3个）
- **choicesLeiDe**: 莱德在场时的专属选项

每个选项可产生以下奖励/惩罚：
- **gold**: 金币变化（可正可负）
- **exp**: 生活经验
- **item**: 获得物品
- **npc / npcAmt**: 影响NPC好感度
- **npc2 / npc2Amt**: 影响第二个NPC好感度
- **result**: 结果叙事文本

### 6.3 属性检定机制

部分选项包含 **statCheck** 属性检定分支：
- 检定属性值是否达到阈值（threshold）
- 知识等级可降低阈值（knowledgeId + knowledgeBonus），体现读书的实际收益
- 成功/失败各有独立的叙事文本和奖励
- 检定结果会显示"检定成功/失败（实际值/阈值）"

**检定公式**：

```
有效阈值 = 基础阈值 - (知识等级 x 知识加成)
结果 = 玩家属性值 >= 有效阈值 ? 成功 : 失败
```

## 九、生活等级系统

生活等级是角色的综合成长指标，由各系统的活动积累：

- 每 **150点** 生活经验升一级
- 每升一级获得 **2点属性点**（可自由分配到力量/灵感/魅力/耐力/技巧）
- 生活经验来源：
  - 职业升级：+50
  - 知识升级：+50
  - 打工事件选项：+5 ~ +25

玩家每周需要缴纳房租，未缴则产生欠款：

| 周数 | 房租金额 |
|------|---------|
| 第1周 | 300金币 |
| 第2周及以后 | 700金币 |

- 缴纳房租时若有历史欠款，会优先偿还欠款
- 金币不足时无法缴纳

## 十四、设计理念

1. **叙事驱动的打工体验**：每个事件都有200-400字的沉浸式叙事，玩家不只是在"点击打工"，而是在体验一段段有温度的故事。

2. **选择有意义**：事件选项影响金币、经验、NPC好感、物品获取，且属性检定让角色Build真正影响叙事走向。

3. **知识的实战价值**：知识等级不只提升属性，还能降低打工事件的检定阈值，形成"读书→打工更顺利→赚更多钱→买更多书"的正向循环。

4. **NPC关系网络**：每种职业绑定1-2个核心NPC，通过打工事件自然地推进关系。事件文本基于角色性格精心撰写，体现每个NPC的独特魅力。

5. **同伴协作维度**：与莱德合作打工提供完全不同的叙事体验和选项，强化同伴羁绊感。
