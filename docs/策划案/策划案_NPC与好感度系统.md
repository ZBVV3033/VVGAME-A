## 1. 系统概述

NPC好感度系统是游戏社交玩法的核心，管理玩家与所有NPC的关系进展。系统分为三个层级：

| 层级 | NPC | 升级机制 | 特点 |
|------|-----|---------|------|
| **主要NPC** | 莱德、K | 每100点升1级 | 升级奖励五维属性各+1，可约会 |
| **特殊NPC** | 黑帮少主、奥梅尔、梅菲斯、乌列尔 | 每50点升1级 | 各有独特奖励机制 |
| **次要NPC** | 辛奇、克丽丝、麦拿拿、黑胡子等10人 | 阶梯式阈值(15/30/50/70/90) | 升级赠家具/书籍 |

## 2. 主要NPC好感度系统

### 2.1 莱德（initialName）

| 属性 | 说明 |
|------|------|
| 好感度变量 | `initialNameAffection` |
| 等级变量 | `initialNameLevel` |
| 升级所需 | **100点/级** |
| 升级方式 | 累计100点后自动升级，剩余好感度滚入下一级 |

**升级奖励**（每升一级）：

| 奖励 | 变量 | 增量 |
|------|------|------|
| 力量 | `initialName_LL` | +1 |
| 逻辑 | `initialName_LG` | +1 |
| 魅力 | `initialName_ML` | +1 |
| 耐力 | `initialName_NL` | +1 |
| 技巧 | `initialName_JQ` | +1 |

**好感度获取途径**：
- 话题对话（感兴趣的话题）：+10
- 约会场景选择：+5 ~ +12（取决于选项）
- 主线/支线任务奖励：不定
- 日常互动事件：不定

**话题偏好**：
- 感兴趣：港口、主城区、铁匠铺、铁匠学徒、港口杂工、小猫
- 不感兴趣：花街、花园小镇、教堂、酒馆、服务员、教士、莱恩、小奥

|------|------|

## 3. 特殊NPC好感度系统

### 3.1 奥梅尔·罗斯巴特（贵族少爷）

| 属性 | 说明 |
|------|------|
| 好感度变量 | `oamelAffection` |
| 升级方式 | 每**50点**升1级（`math.floor(affection/50) + 1`） |
| 初始等级 | 1（0-49点时） |

**技能解锁 —— "贵族的手腕"**：

| 等级 | 所需好感 | 效果 | 变量 |
|------|---------|------|------|
| 2级 | 50点 | 打工工资 **+5%** | `oamelSkillBonus = 5` |
| 3级 | 100点 | 打工工资 **+10%** | `oamelSkillBonus = 10` |

- 技能激活标记：`oamelSkillActive = true`
- 使用 `math.max` 确保只保留最高等级加成，不叠加

**好感度获取**：主要通过晚宴活动（招待客人成功+5，讨好贵族成功+3）

### 3.2 梅菲斯

| 属性 | 说明 |
|------|------|
| 好感度变量 | `meifeiAffection` |
| 等级变量 | `meifeiLevel` |
| 升级方式 | 每**50点**升1级 |

**升级奖励**（每升一级）：

| 奖励 | 数值 | 说明 |
|------|------|------|
| 时薪加成 | +10 金币 | `meifeiWageBonus += 10` |
| 礼仪经验 | +1 | 延迟调用 WorkSystem 处理 |

### 3.3 乌列尔

| 属性 | 说明 |
|------|------|
| 好感度变量 | `urielAffection` |
| 等级变量 | `urielLevel` |
| 升级方式 | 每**50点**升1级 |

**升级效果**：纯叙事性进展，升级提示"你感觉到那个人一直在你身后"。好感等级影响特定剧情走向。

## 5. 话题对话系统

### 5.1 系统机制

- 玩家通过探索、工作等活动**解锁话题**
- 话题存储在 `recentTopics` 列表中（最多10个，FIFO）
- 每个话题有NPC兴趣标记，与感兴趣的NPC聊该话题可获得好感度
- 首次聊到有对话树的话题会解锁为**特殊话题**（`unlockedSpecialTopics`）

### 5.2 话题一览

| 话题 | 描述 | 莱德兴趣 | K兴趣 | 好感奖励 |
|------|------|---------|-------|---------|
| 港口 | 港口的渔船和海风 | **是** | 否 | 10 |
| 主城区 | 主城区的书店和广场 | **是** | **是** | 10 |
| 花街 | 花街的霓虹灯 | 否 | 否 | 10 |
| 花园小镇 | 花园小镇的野花田 | 否 | **是** | 10 |
| 教堂 | 教堂的彩色玻璃 | 否 | **是** | 10 |
| 铁匠铺 | 铁匠铺的炉火 | **是** | 否 | 10 |
| 酒馆 | 酒馆里K调的酒 | 否 | **是** | 10 |
| 服务员 | 在酒馆端盘子的经历 | 否 | **是** | 10 |
| 教士 | 在教堂整理经书的经历 | 否 | **是** | 10 |
| 铁匠学徒 | 打铁的经历 | **是** | 否 | 10 |
| 港口杂工 | 搬货的经历 | **是** | 否 | 10 |
| 莱恩 | 花园小镇遇到的受伤青年 | 否 | 否 | 10 |
| 小奥 | 花街的调酒师 | 否 | 否 | 10 |
| 小猫 | 在酒馆收养的小猫 | **是** | **是** | 10 |

> **莱德偏好总结**：力量型/户外型话题（港口、铁匠、杂工、小猫）
> **K偏好总结**：文艺型/室内型话题（花园、教堂、酒馆、服务员、教士、小猫）
> **共同兴趣**：主城区、小猫

### 5.3 对话树结构

每个话题包含完整的对话树，结构如下：

```
start（起始节点）
  ├─ 选项A → node_A
  │    ├─ 选项A1 → node_A1 → end
  │    └─ 选项A2 → node_A2 → end
  └─ 选项B → node_B → end
```

所有14个话题均配有完整对话树，对话文本通过 `function(name)` 动态插入NPC名称，适配不同NPC使用同一话题。

**对话树示例 —— 小猫话题**：

```
start: "你很喜欢那只小猫？"[NPC]看着你。
  ├─ "嗯，它很可爱。" → node_like
  │    ├─ "你要不要也养一只？" → node_adopt → "...不了。它已经有家了。"
  │    └─ "它更喜欢你。" → node_end → [NPC]没再说话，心情不错。
  └─ "还好，只是觉得可怜。" → node_pity
       ├─ "现在有了。" → node_end
       └─ "它很坚强。" → node_end
```

## 7. 晚宴系统

### 7.1 系统概述

晚宴是与奥梅尔·罗斯巴特相关的社交活动，在花街的"妖精的邀请"举办。

- 共**4种主题**晚宴，随机出现
- 玩家需选择**服装**出席
- 晚宴中有**3种活动**可选

### 7.2 晚宴主题

| 主题 | 名称 | 场景描述 |
|------|------|---------|
| `masquerade` | 假面舞会 | 神秘夜空装扮，半脸面具，香槟玫瑰 |
| `revelry` | 纵情声色 | 红丝绒沙发，划拳赌酒，浓烈香水 |
| `flower` | 赏花宴 | 鲜花装点，玫瑰百合雏菊，花束品鉴 |
| `hunt` | 狩猎夜 | 鹿头标本猎枪，猎装羽毛头饰，棋牌赌注 |

### 7.3 服装系统

每种主题有4种服装可选，每套服装有匹配/不匹配两种评价：

| 服装 | 服装ID |
|------|--------|
| 黑色礼服 | `black` |
| 金色礼服 | `gold` |
| 白色礼服 | `white` |
| 猎装 | `hunt` |

**服装加成**：

| 评价 | 加成 |
|------|------|
| 匹配（matchBonus） | **100** |
| 不匹配（failBonus） | **50** |

> 当前版本所有主题下所有服装的加成数值相同（匹配100/不匹配50），但文本描述各有不同，为后续差异化数值预留了空间。

### 7.4 晚宴活动

每场晚宴提供3种活动：

#### 活动1：帮小奥招待客人

| 项目 | 说明 |
|------|------|
| **解锁条件** | 魅力(ML) ≥ 8 且 礼仪等级(mannerLevel) ≥ 2 |
| **成功效果** | 小费 +150，奥梅尔好感 +5 |
| **失败效果** | 小费 -50 |
| **成功描述** | 引用礼仪课祝酒词，客人刮目相看 |
| **失败描述** | 说错贵族姓氏，罗斯巴特解围 |

#### 活动2：讨好贵族

条件因主题不同而异：

| 主题 | 解锁条件 | 成功小费 | 奥梅尔好感 |
|------|---------|---------|-----------|
| 假面舞会 | 历史等级 ≥ 3 且 礼仪等级 ≥ 2 | **+300** | +3 |
| 纵情声色 | 魅力 ≥ 6 | **+100** | — |
| 赏花宴 | 魅力 ≥ 8 | **+200** | +3 |
| 狩猎夜 | 力量 ≥ 6 | **+150** | +3 |

> 假面舞会的讨好贵族额外包含"中等成功"结果（条件部分满足时），奖励小费+100

#### 活动3：观察学习

| 项目 | 说明 |
|------|------|
| **解锁条件** | 无（始终可选） |
| **效果** | 礼仪经验 +30~50（随机） |
| **描述** | 坐在角落观察，罗斯巴特偶尔送酒指点 |

> 这是保底活动，新手玩家可通过此活动积累礼仪经验，逐步解锁其他活动
