## 主线故事概要

### 世界观

中世纪奇幻港口城镇，表面平静的小镇下隐藏着贵族与平民的阶级冲突，以及暗中操控一切的黑暗教团。

### 三章结构

```
第一章: "营救莱德" → mqStage (0-5)
第二章: "阶级分裂" → mq2Stage + mq2Route (1/2/3)
第三章: "真理之光" → mq3Stage + mq3Ending (1-5)
```

---

## 第一章 - 营救莱德

### 触发条件

- 游戏进行到第 4 天以上
- 在特定地点听到莱德被关押的传闻

### 剧情阶段

| 阶段 | mqStage | 内容 |
|------|---------|------|
| 0 | 未开始 | 日常生活 |
| 1 | 听到传闻 | 在城镇中发现莱德被监禁的线索 |
| 2 | 调查 | 收集信息，确定莱德被关在贵族地下室 |
| 3 | 潜入 | 选择潜行或强攻进入贵族宅邸 |
| 4 | 营救 | 找到莱德并尝试救出 |
| 5 | 完成 | K 助阵逃脱，莱德恢复，加入队伍 |

### 属性检定

- **潜行路线**：JQ (技巧) 检定
- **强攻路线**：LL (力量) 检定
- 检定失败不会 Game Over，但会有负面后果

### 完成奖励

- 莱德正式入队（`initialNameInParty = true`）
- K 关系推进
- 解锁第二章

---

## 第二章 - 阶级分裂

### 触发条件

- 第一章完成
- 目睹贵族马车事件（阶级冲突显现）

### 关键事件

1. **马车事件**：贵族马车撞伤平民，引发公愤
2. **回忆闪回**：莱德身上的外套来自玩家过去的记忆
3. **三条路线选择**（`mq2Route`）

### 路线分支

| 路线 | mq2Route | 立场 | 核心 NPC |
|------|---------|------|---------|
| 路线 1 | 1 | 加入黑帮反抗 | 反抗军领袖 |
| 路线 2 | 2 | 与梅菲斯合作谈判 | 梅菲斯 |
| 路线 3 | 3 | 协助奥梅尔改革 | 奥梅尔 |

### 章节末尾

- 发现黑暗教团在幕后操控一切
- 遇见乌列尔（教会骑士）
- 路线选择影响第三章可用选项

---

## 第三章 - 真理之光

### 触发条件

- 第二章完成

### 关键事件

1. **暴乱爆发**：城镇陷入混乱
2. **神印揭秘**：莱德身上有压制力量的神圣印记
3. **K 的真实身份**：K 是远古守护者
4. **乌列尔的抉择**：在教会使命与真相之间选择
5. **太阳神殿决战**：最终高潮

### 5 种结局

| 结局 | mq3Ending | 描述 | 条件 |
|------|---------|------|------|
| 结局 1 | 1 | 破坏印记，莱德获得力量，一起离开 | 莱德好感度高 |
| 结局 2 | 2 | 保留印记，在小镇平静生活 | 和平路线 |
| 结局 3 | 3 | 加入黑暗教团，颠覆体制 | 邪恶值高（坏结局） |
| 结局 4 | 4 | 牺牲结局（玩家/莱德死亡） | 特定选择链 |
| 结局 5 | 5 | 真结局：和解，改革体制 | 真相度高 + 高好感 |

### 影响因素

- **路线选择**（mq2Route）影响可用结局
- **NPC 好感度**影响最终选项
- **个性属性**（勇敢/冷静等）影响对话
- **真相度**（truth level）追踪，影响结局 5 可用性

## 支线任务

### 任务列表

| 任务名 | 相关 NPC | 内容概要 | 触发条件 |
|--------|---------|---------|---------|
| 失落的画作 | 艾琳 + 罗伊 | 寻回被盗的画作 | 与艾琳对话 |
| 老尤金的过去 | 老尤金 | 退休水手的秘密 | 港口闲逛 |
| 教会之谜 | 克丽丝 | 调查神殿传闻 | 主城区探索 |
| 花园修复 | 莉莉安 | 帮助修复公共花园 | 花园小镇 |

### 任务机制

- 独立的任务标志位（`quest_painting` 等）
- 完成后获得好感度奖励
- 可能解锁特殊物品或段落

### 任务注入

支线任务通过 condition 函数注入到对应地点的选项列表中：

```lua
-- 在 PassageData 的地点段落中
{
    text = "和艾琳聊聊那幅画",
    target = "quest_painting_start",
    condition = function()
        return S.quest_painting == nil and S.npc_ailin_aff >= 15
    end,
}
```

## 剧情系统交互图

```
主线第一章 (MainQuest)
    ├── 完成 → 莱德入队 → BattleSystem
    └── 完成 → 解锁第二章

主线第二章 (MainQuestCh2)
    ├── 路线选择 → mq2Route (1/2/3)
    └── 完成 → 解锁第三章

主线第三章 (MainQuestCh3)
    ├── 读取 mq2Route → 影响可用选项
    ├── 读取 NPC 好感度 → 影响结局
    └── 5 种结局 → mq3Ending

支线任务 (SideQuests)
    ├── 独立于主线
    ├── 通过 NPC 好感度触发
    └── 奖励好感度 + 物品
```
