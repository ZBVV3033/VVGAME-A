## NPCSystem - 关系管理

### 主要 NPC（100 分制）

| NPC | 初始好感 | 好感等级 | 特殊状态 |
|------|---------|---------|---------|
| 莱德 (Leide) | 0 | 1-5 级 | 可同居、可入队 |
| K | 0 | 1-5 级 | 双形态（法师/剑士） |
| 奥梅尔 (Oamel) | 0 | 1-5 级 | 贵族路线关键 |

### 好感等级

```
等级 1: 0-19   初识
等级 2: 20-39  熟悉  → 解锁约会
等级 3: 40-59  亲近  → 解锁特殊对话
等级 4: 60-79  亲密  → 解锁同居选项
等级 5: 80-100 恋人  → 解锁结局相关选项
```

**升级奖励**：好感度溢出（超过等级阈值）→ 升级 → 五维属性全 +1

### 城镇 NPC（阈值制）

15+ 个城镇 NPC，每个有 5 个好感度阈值：

```lua
阈值: [0, 15, 30, 50, 70, 90]
每个阈值解锁新的对话和事件
```

### 好感度获取方式

| 方式 | 好感变化 | 频率限制 |
|------|---------|---------|
| 日常对话 | +1 ~ +3 | 每天 1 次 |
| 赠送礼物 | +3 ~ +10 | 每天每人 1 次 |
| 约会 | +5 ~ +15 | 每天 1 次 |
| 关键词分享 | +1 ~ +5 | 无限制 |
| 主线/支线 | +5 ~ +20 | 一次性 |
| 随机事件 | +2 ~ +8 | 随机触发 |

### 礼物系统

```lua
-- 每天每个 NPC 限送 1 次
NPCSystem.giveGift(npcName, itemName)

-- 礼物价值决定好感增加量
-- 追踪礼物历史，避免重复送同样的东西
```

### 约会系统

- **解锁条件**：好感度等级 ≥ 2
- **约会地点**：7 个（花园、港口、酒馆、商业区等）
- **约会流程**：多个场景段落 + 选择 → 不同好感度变化

```lua
-- 约会记录
GameState.state.initialNameDateLog = {
    { location = "花园", date = "499年1月5日", result = "happy" },
}
```

## KeywordSystem - 关键词收集

### 概念

玩家通过各种活动收集"关键词"，这些关键词可以在与 NPC 对话时使用，匹配 NPC 兴趣获得好感度加成。

### 关键词分类（16 类）

冒险、港口、铁匠、动物、文化、烹饪、花园、社交、礼仪、商业、八卦、学术、历史、奢侈、权力、神秘

### NPC 兴趣匹配

| NPC | 喜欢 | 中性 |
|------|------|------|
| 莱德 | 冒险、港口 | 文化 |
| K | 文化、烹饪、花园 | 冒险 |
| 梅菲斯 | 社交、礼仪、商业、八卦 | - |
| 奥梅尔 | 学术、历史、奢侈、权力 | - |

### 好感度加成

```lua
-- 分享喜欢的关键词
affectionBonus = 3 ~ 5

-- 分享中性关键词
affectionBonus = 1 ~ 2

-- 分享不感兴趣的关键词
affectionBonus = 0
```

### 关键词获取途径

| 途径 | 获取的关键词类型 |
|------|---------------|
| 读书 | 文化、学术、历史 |
| 打工 | 对应职业相关 |
| 探索森林 | 冒险、动物、神秘 |
| 逛商业区 | 商业、社交、奢侈 |
| 参加宴会 | 礼仪、八卦、社交 |

### 与 AI 聊天集成

收集到的关键词会作为上下文注入到 LLM 对话中，让 AI NPC 能围绕这些话题展开对话：

```lua
-- ChatUI 构建上下文时注入
context.keywords = KeywordSystem.getCollectedKeywords()
-- AI 可以主动提起这些话题
```

## 关系发展路线图

```
初识 (Lv.1)
  │ 日常对话 + 礼物
  ↓
熟悉 (Lv.2) → 解锁约会
  │ 约会 + 关键词分享
  ↓
亲近 (Lv.3) → 特殊对话/事件
  │ 持续互动 + 主线推进
  ↓
亲密 (Lv.4) → 可同居
  │ 同居事件 + 每日互动
  ↓
恋人 (Lv.5) → 影响结局选择
```

### 同居系统

当好感度达到 Lv.4 并选择同居后：

- NPC 出现在家中各房间
- 触发专属同居事件（每人 3 个）
  - 早晨互动
  - 共进晚餐
  - 日常趣事
- 在 HomeSystem 中处理相关段落
