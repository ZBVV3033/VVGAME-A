## PassageData - 段落数据库

### 概念

这是整个游戏最大的模块（5151 行），本质上是一个 **Twine 风格的交互式文本数据库**。每个"段落"(passage) 对应游戏中的一个画面/场景。

### 段落结构

```lua
passages["段落名"] = {
    text = "这是场景描述文本...",
    choices = {
        {
            text = "选项显示文本",
            target = "目标段落名",           -- 静态跳转
        },
        {
            text = "动态选项",
            action = function()              -- 执行操作
                GameState.state.money = GameState.state.money + 10
                return "结果段落名"
            end,
        },
        {
            text = "条件选项",
            target = "某段落",
            condition = function()           -- 满足条件才显示
                return GameState.state.money >= 50
            end,
        },
    },
    modal = true,                           -- 以弹窗形式显示（可选）
}
```

## TownLife - 城镇随机事件

### 概念

DOL（Degrees of Lewdity）风格的区域随机事件系统。玩家进入某个区域时，可能触发随机事件。

### 6 个区域事件池

| 区域 | 事件数量 | 典型事件 |
|------|---------|---------|
| 商业区 | 10-20 | 商人争吵、打折促销、小偷追逐 |
| 港口 | 10-20 | 船员故事、货物搬运、海怪传闻 |
| 花园小镇 | 10-20 | 画家写生、花卉展、迷路小孩 |
| 主城区 | 10-20 | 教堂仪式、贵族巡游、学术辩论 |
| 花街 | 10-20 | 表演艺人、夜市、神秘商人 |
| 贫民窟 | 10-20 | 乞丐请求、黑市交易、帮派冲突 |

### 事件机制

```lua
-- 每日限制：最多 3 个事件
townEventSeen[area] = count  -- 追踪每个区域已触发事件数

-- 事件注入到地点段落的选项列表中
-- 通过 condition 函数控制触发条件
```

### 属性检定事件

部分事件需要属性检定：

```lua
-- 检定公式
successRate = baseRate + statValue * multiplier

-- 例：力量检定
if math.random() < (0.3 + S.LL * 0.05) then
    -- 成功结果
else
    -- 失败结果
end
```

### NPC 交叉事件

某些事件涉及多个 NPC 同时出现：
- 莱德 × K 联合事件
- 奥梅尔 × 老尤金 交互

## RandomEvents - 生存触发事件

### 概念

当玩家的生存指标达到危险阈值时触发的事件。

### 触发条件

| 指标 | 阈值 | 事件类型 |
|------|------|---------|
| 饱腹度 ≤ 25 | 饥饿事件 | 食物商贩、乞讨选项 |
| 疲劳度 ≥ 70 | 疲劳事件 | 公共场所打盹、精疲力竭 |
| 压力 ≥ 70 | 压力事件 | 情绪崩溃、心理辅导 |
| 清洁度 ≤ 30 | 清洁事件 | 社交尴尬、澡堂 |

### 每日限制

每天最多 5 个生存事件（独立于 TownLife 的 3 个）。

### 链式事件

部分事件是多阶段的：

```
事件阶段 1 → 选择 A → 事件阶段 2a → 结果
                    → 选择 B → 事件阶段 2b → 结果
```

## HomeSystem - 家庭系统

### 房间导航

```
家
├── 卧室    → 睡觉、换衣服
├── 客厅    → 休息、与同居 NPC 互动
├── 厨房    → 烹饪（→ CookingSystem）
├── 菜园    → 种植（→ FarmingSystem）
└── 门口空地 → 出门、其他活动
```

### 同居 NPC 互动

如果有 NPC 住在家中（`initialNameAtHome = true`），各房间会出现专属互动选项：

| NPC | 事件 1 | 事件 2 | 事件 3 |
|------|--------|--------|--------|
| 莱德 | 早晨叫醒 | 一起做饭 | 客厅聊天 |
| K | 魔法晨练 | 分享读书心得 | 花园散步 |
| 奥梅尔 | 优雅早餐 | 讨论政务 | 音乐欣赏 |

### 日常活动

| 活动 | 效果 | 消耗时间 |
|------|------|---------|
| 睡觉 | 疲劳度 → 0, 时间跳到早上 8:00 | 到次日 |
| 洗澡 | 清洁度 → 100 | 1 小时 |
| 烹饪 | → CookingSystem | 1 小时 |
| 种菜 | → FarmingSystem | 30 分钟 |

## 内容扩展指南

### 添加新地点

1. 在 `PassageData.lua` 中添加地点 Hub 段落
2. 在 `十字路口` 段落的选项中添加新入口
3. 在 `SceneBackground.lua` 中添加背景绘制
4. （可选）在 `TownLife.lua` 中添加区域事件池

### 添加新随机事件

1. 选择触发类型（区域型 → TownLife / 生存型 → RandomEvents）
2. 在对应模块的事件池中添加事件定义
3. 设置触发条件和属性检定
4. 编写成功/失败结果文本

### 添加新约会场景

1. 在 `PassageData.lua` 中添加约会段落链
2. 格式：`{NPC名}_约会_{地点}_{编号}`
3. 设置好感度变化
4. 添加到约会地点选择列表中
