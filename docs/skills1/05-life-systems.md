## WorkSystem - 打工系统

### 4 种职业

| 职业 | 关联属性 | 初始工资 | 满级工资 | 工作地点 |
|------|---------|---------|---------|---------|
| 服务员 (waiter) | LL (力量) | 30金/班 | 60金/班 | 酒馆 |
| 见习教士 (cleric) | LG (灵感) | 30金/班 | 60金/班 | 教堂 |
| 铁匠学徒 (blacksmith) | NL (耐力) | 30金/班 | 60金/班 | 铁匠铺 |
| 港口杂工 (laborer) | LL (力量) | 30金/班 | 60金/班 | 港口 |

### 工作机制

```
工作 → 消耗时间 (2-4 小时) → 增加疲劳
     → 属性检定（基础 + 等级 + 属性值）
     → 成功 → 获得工资 + 经验
     → 失败 → 获得少量经验，无工资
```

### 升级公式

```lua
-- 经验需求递增
expNeeded = level * 50

-- 工资增长：每级 +3金
wage = baseWage + (level - 1) * 3
```

### 随机工作事件

工作过程中随机触发好/坏事件：
- 好事件：额外小费、老板赞赏（+金钱、+属性）
- 坏事件：打碎餐具、被顾客投诉（-金钱、+压力）

## CookingSystem - 烹饪系统

### 食材（15 种）

从商店购买或菜园收获，存储在 GameState 中。

### 食谱（9 道菜）

| 等级 | 菜名 | 食材需求 | 恢复饱腹度 |
|------|------|---------|-----------|
| 0 | 烤土豆 | 土豆×1 | 18 |
| 0 | 蔬菜汤 | 白菜×1, 胡萝卜×1 | 22 |
| 0 | 煎蛋 | 鸡蛋×1 | 20 |
| 1 | 番茄炒蛋 | 番茄×1, 鸡蛋×1 | 28 |
| 1 | 洋葱鸡肉卷 | 洋葱×1, 鸡肉×1 | 30 |
| 2 | 奶油蘑菇汤 | 蘑菇×1, 奶油×1 | 35 |
| 2 | 红烧鱼 | 鱼×1, 酱油×1 | 38 |
| 2 | 猪肉饺子 | 猪肉×1, 面粉×1 | 40 |
| 3 | 海鲜烩饭 | 虾×1, 米×1, 黄油×1 | 50 |

### 烹饪机制

- 消耗时间（约 1 小时）
- 消耗食材
- 成功率与烹饪等级相关
- 可以自己吃（恢复饱腹度）或出售赚钱
- 烹饪经验积累 → 解锁新食谱

## FarmingSystem - 种植系统

### 菜园

- **3 块地**：每块独立管理
- 位于家中"菜园"房间

### 种子（6 种）

| 种子 | 生长天数 | 收获量 |
|------|---------|--------|
| 土豆 | 3 天 | 2-4 |
| 胡萝卜 | 2 天 | 2-3 |
| 白菜 | 3 天 | 1-3 |
| 番茄 | 4 天 | 2-5 |
| 洋葱 | 3 天 | 2-4 |
| 小麦 | 2 天 | 3-5 |

### 生长阶段

```
0: 空地 → 播种
1: 已播种 → 等待
2: 发芽 → 浇水
3: 生长中 → 浇水
4: 成熟 → 收获
```

### 机制

- **每天浇水**才能推进生长（由 `TimeSystem.onDayChange` 驱动）
- 忘记浇水 → 不生长（不会枯萎）
- 收获后获得食材 → 用于烹饪或出售
- 种子从商店购买

## UniversitySystem - 大学系统

### 4 个专业

| 专业 | 属性加成 | 战斗加成 | 课程安排 |
|------|---------|---------|---------|
| 战士学 | LL+2, NL+1 | 物理伤害加成 | 周一/三/五 |
| 魔法学 | ML+2, LG+1 | 魔法伤害加成 | 周二/四/六 |
| 神学 | LG+2, ML+1 | 魔法防御加成 | 周一/三/五 |
| 烹饪学 | JQ+2, NL+1 | 烹饪经验加成 | 周二/四/六 |

### 课程机制

- **上课时间**：9:00 或 14:00，每节 90 分钟
- **任意两个专业可同时修读**（课程不冲突）
- 上课消耗时间，获得对应经验
- 随机课堂描述（增加沉浸感）

### 等级与毕业

```
最高等级: 5 级
每级所需经验: level * 100

毕业效果:
  战士学 → 解锁战士职业技能
  魔法学 → 解锁法师职业技能
  神学   → 魔法防御永久加成
  烹饪学 → 烹饪经验获取加成
```

## 系统间联动

```
FarmingSystem ──→ CookingSystem ──→ GameState.satiety
     │                  │
     │                  └──→ 出售赚钱 → GameState.money
     │
     └──→ 收获食材 → GameState.ingredients

WorkSystem ──→ GameState.money ──→ 购买种子/食材
     │
     └──→ TimeSystem ──→ 生存指标衰减

UniversitySystem ──→ BattleSystem (职业加成)
        │
        └──→ GameState (属性提升)
```
