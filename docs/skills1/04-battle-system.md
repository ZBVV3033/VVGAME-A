# Skill 04 - 战斗系统

## 涉及模块

| 模块 | 文件 | 行数 | 职责 |
|------|------|------|------|
| BattleSystem | `systems/BattleSystem.lua` | 3008 | 回合制战斗全部逻辑 |

---

## 系统概览

回合制战斗 + 10 层森林地牢探索 + 队伍编成 + 技能系统 + 商人系统。

---

## 森林层级

| 层数 | 难度 | 敌人类型 | 特殊 |
|------|------|---------|------|
| 1-2 | 初级 | 小石块、毒蘑菇、荆棘藤 | 新手区 |
| 3-4 | 中级 | 苔藓巨石、暗影狼、火焰精灵 | 猎手级 |
| 5 | BOSS | 石像鬼统领 | 中期 BOSS |
| 6-9 | 高级 | 强化变种 | 难度递增 |
| 10 | 终极 BOSS | 森林之主 | 最终挑战 |

**遭遇率**：每次探索 55% 概率触发战斗

**非战斗事件**：发现水果、温泉、神秘少女

## 敌人模板

```lua
BattleSystem.ENEMY_TEMPLATES = {
    ["小石块"] = {
        name = "小石块",
        hp = 50, maxHp = 50,
        power = 3, insight = 2,
        speed = 4, def = 5,
        mdef = 0.2, skill = 1,
        atkBase = 3, matkBase = 2,
        expValue = 50, gold = 10,
        skillCycle = { "attack", "harden", "attack", "attack", "smash" },
        emergencySkill = "smash",
    },
    -- ...更多敌人
}
```

### 敌人属性说明

| 字段 | 说明 |
|------|------|
| `hp/maxHp` | 生命值 |
| `power` | 物理攻击力 |
| `insight` | 魔法攻击力 |
| `speed` | 速度（决定出手顺序） |
| `def` | 物理防御 |
| `mdef` | 魔法防御（百分比减伤，0-1） |
| `skillCycle` | AI 技能循环序列 |
| `emergencySkill` | 低 HP 时触发的技能 |
| `expValue/gold` | 击败奖励 |

```

```

## 战斗流程

```
1. 生成敌人（根据森林层级从模板池随机）
   ↓
2. 计算出手顺序（按 speed 排序）
   ↓
3. 玩家回合：
   ├── 显示技能菜单
   ├── 选择目标
   └── 执行技能 → 伤害计算
   ↓
4. 敌人回合：
   ├── 按 skillCycle 顺序使用技能
   ├── HP < 阈值 → 使用 emergencySkill
   └── 执行攻击
   ↓
5. 回合结束检查：
   ├── 全部敌人阵亡 → 胜利（EXP + Gold）
   ├── 玩家阵亡 → 失败（返回营地）
   └── 否则 → 继续下一回合
```

### 伤害计算

```lua
-- 物理伤害
damage = (power + atkBase) * skillMultiplier - targetDef

-- 魔法伤害
damage = (insight + matkBase) * skillMultiplier * (1 - targetMdef)

-- 大学加成
damage = damage * (1 + uniCombatBonus)
```

### 逃跑机制

```lua
escapeChance = 0.4 + (playerSpeed - avgEnemySpeed) * 0.05
-- 基础 40% + 速度差加成
```

## 升级系统

```lua
-- 经验需求
expNeeded = level * 100

-- 升级效果
maxHp += 10
maxMp += 5
power += 1
insight += 1
speed += 0.5
def += 1
```

## 商人系统

森林探索中可能遇到商人，提供：

- 装备升级
- 特殊物品

## 与其他系统的交互

| 交互对象 | 方式 |
|---------|------|
| GameState | 读写玩家战斗属性、森林层级、经验/金币 |
| UIManager | 通过特殊段落 "战斗" 路由进入战斗界面 |
| UniversitySystem | 读取职业加成 `uniCombatBonus_*` |
| MainQuest | 第一章完成后莱德加入队伍 |
