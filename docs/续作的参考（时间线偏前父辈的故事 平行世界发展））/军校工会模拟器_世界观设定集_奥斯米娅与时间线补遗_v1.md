# 悠L/悠K · 世界观设定集（奥斯米娅终身未婚补遗 + 时间线修正版）v1

> 用途：作为《军校工会模拟器》世界观补遗参考，同时可改写为游戏内可阅读书籍文本。  
> 基准：统一时间线以《悠L》历483年、《悠K》历461年为锚点。

---

## 第一部分：奥斯米娅的婚姻选择

奥斯米娅·罗斯巴特终身未婚。这在日轮王国的历史上是前无古人的事。不是没有人求娶她——她十九岁登基，二十五岁打服了边境，三十岁把日轮王国推到了鼎盛。求娶她的使节从王都排到边境，有邻国的王子，有本国的公爵，有教会的红衣主教。她一个都没嫁。

她的理由是：女人不需要通过婚姻来证明自己的价值。她说“我骑马打仗，我立法治国，我修路建城。我做的这些事，和我是谁的女儿、谁的妻子、谁的母亲，没有任何关系”。她还说“如果我的权力来自我的丈夫，那我的改革就是他的施舍，不是我的意志”。她不想把自己的命挂在别人身上。她见过太多女人——嫁了人之后，名字没了，财产没了，连说话的资格都没了。她不要那样。她要站着活。站着活到死。

这不是任性。这是政治。她要用自己的一生证明：女人可以不靠父亲、不靠丈夫、不靠儿子，独自站在王座上。她的王冠是自己戴上去的，不是别人替她扶着的。她做到了。她活着的时候，没有人敢说“女人不该当国王”。她死以后，他们说了很多年。

## 第二部分：终身未婚为何成为倒台的原因

奥斯米娅的终身未婚是她倒台的主要原因。不是唯一原因，但贵族们掰开揉碎说给议会听、说给教会听、说给百姓听的理由，就是这个。不是因为她打输了仗，她没有。不是因为她搞砸了改革，她没有。不是因为她得罪了所有人，她得罪了所有人，但她活着的时候没人敢动她。她死以后，他们开始算账了。

第一笔账：她没有继承人。这是最要命的。一个没有孩子的国王，死后王座空着，谁来坐？她的弟弟奥斯特利亚公爵说“我来”。议会说“好”。教会说“太阳神的旨意”。没有人提起奥斯米娅的遗嘱——她写了，但她写的是谁？她写的是“王位由议会选举产生”。这句话比她的终身未婚更让贵族们害怕。选出来的国王，不是生出来的国王，那他们家的爵位是不是也要选？他们不敢让她活到把这条也写进法律里。所以她必须死。不是身体死，是政治死。把她从王座上请下来，请到花园里，请到蔷薇花丛旁边，请到再也没有人听她说话的地方。

第二笔账：她得罪了所有人。贵族们恨她，因为她削了他们的权。教会恨她，因为她修了下水道，穷人不去求神治病了。商人们怕她，因为她太强了，强到不知道她下一步要干什么。她的弟弟也恨她，恨了半辈子。她活着的时候，所有人都低着头，不敢说。她死了，他们抬起头，说“看，她没有孩子，她没有丈夫，她什么都没有。她的一切都是我们给她的”。不是。她的一切都是她自己挣来的。但他们需要这样说。这样说，他们才能睡得着觉。

第三笔账：她的存在本身就是威胁。一个终身未婚的女王，证明了女人可以不靠男人活着。这是比任何法律都危险的先例。如果女人可以不靠男人活着，那女儿为什么要嫁出去？那妻子为什么要听丈夫的话？那寡妇为什么要被赶出家门？她的存在，就是一把刀，架在每一个男人的脖子上。他们要把这把刀拿下来。所以他们把她的王冠摘了，把她的名字从史书上刮了，把她关进花园里，让她坐在秋千上，看花，喂鱼，等死。她死了。他们安全了。

## 第三部分：奥斯米娅退位后的最后三年

她被关在花园里三年。不是牢房，是王宫后面的花园。有蔷薇，有喷泉，有她小时候荡过的秋千。她弟弟来看她，站在花园门口，不敢进来。她朝他招手，说“进来坐”。他走进来，坐在她旁边。两个人不说话，只是坐着。风吹过来，蔷薇花瓣落了一地。

她问他“议会还在吗”。他说“在”。她问他“女子学校还在吗”。他说“在”。她问他“下水道还在修吗”。他说“在修”。她笑了。她说“那就好”。她不在乎王座，她在乎的是那些东西还在不在。议会还在，学校还在，下水道还在修。她做的事不会因为她死了就没了。她相信。她必须相信。

她走的时候，手里还攥着一片蔷薇花瓣。她弟弟站在门口，没有进去。他不敢进去。他怕自己后悔。他不想后悔，但他还是后悔了。后悔了一辈子。后来史书上写“奥斯特利亚公改朝换代，罗斯巴特氏衰微”，写“女王逊位，薨于别苑”，写“新旧更替，天命所归”。没有人写她是终身未婚的女王。没有人写她立法让女人可以上学、可以继承家产、可以在法庭上说话。没有人写她修了下水道，让王都的人不用再喝脏水。没有人写她站在城墙上说“那里也是我们的”。他们只写她没有孩子，没有丈夫，什么都没有。好像她活着的时候做过的事，都不算数。

## 第四部分：对后世的影响

奥斯米娅死了，但她立的法没有死。议会还在吵，女子学校还在上课，下水道还在修。女人可以继承爵位，可以在法庭上作证，可以读书识字。这是她留给她们的。不是施舍，是权利。她用自己的命替她们挣来的。但她没有挣完。她死以后，再也没有女人坐过王座。不是不能，是不敢。贵族们怕了。怕再出一个奥斯米娅，怕再一个终身未婚的女王，怕再一把架在他们脖子上的刀。所以他们对每一个有野心的女人说“你看看奥斯米娅，她什么下场”。她们看了。她们低头了。她们嫁人了。她们沉默了。一百年。

阿斯特的祖母是罗斯巴特家的人，她嫁进王室的时候，她的嫁妆里有一本奥斯米娅写的**《万民之誓》**手抄本（外人多称「盟誓书」）。她把它锁在箱子里，谁也没给。阿斯特小时候问过她“奥斯米娅是什么样的人”。她说“是一个站着活的人”。他说“我也想站着活”。她笑了。她说“你站着，但要小心。站着的人，容易被打”。他记住了。他站着。他笑着。他把所有的不甘咽下去，把所有的账记在心里，把所有的刀藏在笑后面。他站着。他没有被打倒。不是因为不怕，是因为奥斯米娅站过。她站过，所以他敢站。她立过法，所以他敢说话。她修过路，所以他敢往前走。他不知道自己在走她走过的路。他只是在走。走了一百年，还在走。

## 第五部分：与《悠K》的呼应

一百年后，莱昂哈特在军校读书。**通识历史课的小测与期考会考知名君主全名、各大公爵家族与重大事变**——他**背得出**「奥斯米娅·罗斯巴特」和「盟誓冬市之乱」的条目，却未必在情感上与她的生平共情。校园公园里，她的铜像与当年**攻破皇都的瓦勒姆侯爵**像并立——那是一种官方叙事的**歉意式并置**，他每次路过都别扭。他只知道自己的诅咒，自己的画，自己等的那个人。他不一定知道一百年前她**作为人**如何站着活过，但他姓瓦勒姆。瓦勒姆家的人站着活，站着死，站着等一个人来。他不知道这算不算遗传。他只是站着。站了一百年，还在站。

阿斯特知道奥斯米娅。他知道她是谁，知道她做了什么，知道她怎么死的。他每次路过王都的议会大厅，都会停下来看一眼。门口有一块石碑，上面刻着**《万民之誓》**的开卷句：「**凡载于国册之民，同负役赋之责，亦同享法理之庇。**」他知道这是他的祖先写的。他站在那里，不进去，也不说话。只是站着。他站着的时候，会想奥斯米娅站在城墙上的样子。她看着远方，说“那里也是我们的”。他也在看远方。他看的是瓦勒姆领地的方向。他不知道她看不看得见。他只知道她站过。他站着。这就够了。

## 第六部分：时间线修正版（统一基准）

### 6.1 说明

本文档整合历史讨论，统一时间线基准：

- 《悠L》主线发生在 **历483年**（诺兰 14 岁，在艾瑟顿镇）
- 《悠K》平行世界发生在 **历461年**（莱昂哈特 18 岁，进军校）

### 6.2 历史分期

| 时期 | 大致时间 | 说明 |
|---|---|---|
| 开国 | 约历前200年 | 凡人皇帝推翻众神，建立日轮王国 |
| 罗斯巴特王朝 | 约历前200年-历361年 | 罗斯巴特家执政约560年 |
| 奥斯米娅时代 | 约历331-361年 | 奥斯米娅女王在位，鼎盛时期 |
| 罗斯巴特覆灭 | 历361年 | 奥斯特利亚政变 |
| 奥斯特利亚王朝 | 历361年-今 | 至今约122年 |
| 《悠K》主线 | 历461年 | 奥斯特利亚王朝建立100年后 |
| 《悠L》主线 | 历483年 | 奥斯特利亚王朝建立122年后 |

### 6.3 奥斯米娅时代（约历331-361年）摘要

- 约历331年：奥斯米娅登基（19岁），边境战事、贵族叛乱、国库空虚并存。  
- 约历340年：**《万民之誓》**颁布，以「君民同誓」约束征敛与刑名，王座与国法同受覆核（后世简称**「盟誓书」**）。  
- 约历345年：议会机制成形，女性权益立法、女子学校、经济与道路改革推进。  
- 历361年：奥斯米娅退位，奥斯特利亚政变；**《万民之誓》一度不被新朝正式承认**，约十年抗争后**被迫恢复国本地位**（见 §6.4）。

### 6.4 奥斯特利亚王朝（历361年后）摘要

- **改朝之初（历361年起）**：奥斯特利亚朝**未在法统上正式承认《万民之誓》（盟誓书）**，试图以暂行令、军兴特例架空其核心条款；议会一度空心化，民间与**中低贵族**不满累积。  
- **约十年内（历361—371年，具体年份可再钉）**：**广大民众与中低贵族**强烈抗议、串联与局部冲突迫使新朝**重新承认并沿用《万民之誓》**作为国本之一，议会与刑名覆核机制实质回归。其中**王都冬市暴动与围城外交涉**等事件在通史中合称 **「盟誓冬市之乱」**（详见通识课考纲）。  
- **史学评价（历461年前后已稳定）**：后世编纂**普遍正确承认**这一转折的历史分量——即「新朝若不接续盟誓书，合法性在日常赋税与刑名上无法落地」；替讳之说仍在，但非主流。  
- 历461年（《悠K》）：王室争储与**议会**博弈成为政治主轴（议会话语权离不开上述十年抗争的遗产）。  
- 历483年（《悠L》）：老王衰迈，诸王子派系斗争加剧。

### 6.6 与《悠K》剧情关联（可直接用作书内条目）

1. **议会舞台**：奥斯米娅遗产是当代争储政治的主战场。  
2. **女性教育与法权**：女子学院与女性受教机会具备历史来源。  
3. **基础设施延迟兑现**：下水道等“百年政策”的现实落差可做城市叙事。  
4. **前朝余波**：罗斯巴特后裔的“笑着活着、账没算完”构成阿斯特线深层动机。
