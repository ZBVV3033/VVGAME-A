# 军校工会模拟器｜世界观参考：世界线与时间线区分 v1

> 用途：给“前作补充世界观 / 多版本并存 / 回溯设定”提供统一口径。  
> 目标：避免把“世界线分歧”误写成“时间顺序矛盾”，也避免用“时间线补丁”去偷改世界规则。

---

## 0. 先给结论（最短可执行版）

- **世界线（Worldline）**：同一套宇宙里“**世界规则与历史结论**”的一条版本轨道。它决定**这个世界是什么**（法则、制度底盘、魔法体系、王权结构、重大历史结局、是否发生过某次灾厄）。  
- **时间线（Timeline）**：在某一条世界线里，“**事件发生的先后顺序**”与“某个时间点世界是什么状态”。它决定**这条世界线里先后发生了什么**（年份/季节/学期/人物年龄/事件次序）。

一句话区分：  
- **世界线回答“哪个版本的世界”**；  
- **时间线回答“这个版本里什么时候发生了什么”**。

---

## 1. 名词定义（写作时必须对齐）

### 1.1 世界观（Setting / Worldbuilding）

世界观 = 世界线共享或世界线内稳定的“底盘”，通常包括：
- **历史维度**：重大事件、国家兴亡、战争与条约、宗教与王朝更替的结论口径
- **地理维度**：版图与地名、交通成本（步行/马车/航道）、城市与校区关系
- **制度维度**：王权与贵族体系、军校/工会/法师院的权力结构与日常规程
- **技术维度**：时代气质为“中世纪偏近代”；现代功能以**魔法/魔导科技**替代；禁止现实工业口径硬迁移

### 1.2 世界线（Worldline）

世界线是“同一题材/同一宇宙的不同版本”。它的差异通常来自：
- 重大历史事件是否发生/结局不同（例如某次战争结局、某个王室继承结果）
- 世界规则不同（例如魔法体系是否公开、某类诅咒是否普遍、某种仪轨是否存在）
- 关键组织的存废与权力版图不同（法师院、教会、工会制度的合法性不同）

**世界线差异一旦成立**，就会对无数细节产生连锁反应；因此它必须被当成“版本开关”，而不是在正文里偷偷改。

### 1.3 时间线（Timeline）

时间线是“同一条世界线里事件的顺序”。它的差异通常来自：
- 事件在不同年/月/周发生（谁先遇见谁、先入学还是先建工会）
- 人物年龄与身份在某个时间点是什么状态（尚未入学/已入学、是否同居、是否已签某项手续）
- 同一事件的“前后因果”是否自洽（先有传闻才有行动，还是先发生行动才引发传闻）

时间线的矛盾大多表现为“前后不可能同时成立”，需要用“补齐顺序/补齐动机/加回流点”修复，而不是改世界规则。

## 2. 常见错误（以及怎么一眼看出属于哪类问题）

### 2.1 把世界线问题当时间线修

**症状**：  
- 为了让某段剧情成立，临时引入一个“世界常规配置”级别的新设定（新科技、新制度、新教派）来兜底  
- 或者把一个“全世界都会变”的规则写成“刚好这天碰上”

**判定**：  
- 如果改动会影响“所有城镇/所有军校/所有贵族”的日常规则，它是**世界线/世界观**问题，不是时间线问题。

**正确做法**：  
- 先明确这是“世界线差异”（另立世界线），还是“本世界线已有设定的场景特批”。  
- 若是特批，必须写：`【场景特批】用途/来源/限制`，并解释为什么不会变成常规配置。

### 2.2 把时间线问题当世界线分歧

**症状**：  
- 同一条故事里出现“昨天还不知道，今天却引用了只可能明天才发生的证据”  
- 或人物关系推进顺序不可能（先同居后才初见）

**判定**：  
- 如果只需要调整“谁先说/谁先看见/哪天办手续”，它是**时间线**问题。

**正确做法**：  
- 补齐事件的“前置触发→发生→后果→回流点”的顺序；  
- 用“传闻版本”“站位差分”“台词开场条件”去承接，而不是删掉内容。

## 3. 本项目推荐的写作标注法（建议统一）

### 3.1 世界线编号（建议）

用“世界线”管理版本差异，建议格式：
- `WL-0`：主世界线（当前 Demo/正史口径默认）
- `WL-PRE`：前作世界线（若前作与主线规则一致，也可与 `WL-0` 合并，不另起）
- `WL-X`：明确分歧的实验世界线（只有当你确认存在“规则级别差异”才启用）

**最小要求**：每份正文或设定补充稿，开头注明它属于哪条世界线（不写默认 `WL-0`）。

### 3.2 时间线标签（建议）

时间线建议用“相对时间 + 锚点”：
- 相对时间：`Day -2 / Day -1 / Day 0 / Week1`（或“入学前两天”等）
- 锚点事件：例如“入学报到”“校门求婚”“学生会换届”

写法例：
- `TL(WL-0): Day -2`  
- `TL(WL-0): Week1 / 荣誉格斗准备期`

### 3.3 分歧点（Divergence Point）写法

当你需要写“前作补设定”，最容易发生的是“把补充写成改写”。推荐固定三段标注：

```text
【分歧点】DP-xxx（世界线/时间线）
用途：说明这次补充是“世界线差异”还是“时间线补齐”
影响范围：会影响哪些角色/地点/制度（写 3 条以内）
回流策略：如何确保后续主线仍能对接（例如：只改变传闻版本，不改变主事件）
```

## 4. 给“前作补充世界观”的落地模板（可直接复制）

> 你每新增一块设定，建议按以下模板写，避免混淆。

### 4.1 单条世界观补充条目模板

```text
【条目名】（建议可检索的短名）
所属：WL-?（世界线） / TL(WL-?): ?（时间线范围，如“入学前”“三年前”“某学期”）

1) 这是世界线还是时间线？
- 世界线：改的是规则/结论（写明原口径与新口径）
- 时间线：补的是顺序/缺失环节（写明前置与后果）

2) 四维自查（必须写一句话过关）
- 历史：是否与既有重大史实冲突？
- 地理：是否改变路程/动线口径？
- 制度：是否改变学院/工会/王权的常规运作？
- 技术：是否越过“中世纪偏近代 + 魔法/魔导替代”边界？

3) 对剧情的可用钩子（写 1～3 条）
- 传闻版 / 规程版 / 目击版（优先写“玩家可看见的表现”）

4) 禁区说明（可选）
- 明确“不改变哪些东西”（防止未来被误读为世界线差异）
```

### 4.2 “场景特批”模板（当且仅当必须）

```text
【场景特批】
用途：为什么必须出现（剧情必须性）
来源：来自谁/哪条组织链条（在世界观内可解释）
限制：为什么不会成为常规配置（一次性/实验/成本/法规/保密）
```

## 5. 本项目硬口径（与世界线/时间线相关的高频踩雷点）

> 本节只写“容易在前作补充时写乱”的硬口径。

- **时代与技术**：世界观底盘为“中世纪偏近代”；涉及现代功能优先用**魔法/魔导科技**替代；禁止现实工业术语硬迁移。  
- **制度与日常**：军校/王权/贵族礼制与“程序”是世界的常态表达方式；若要写破格机制，优先走 `【场景特批】`。  
- **角色动线口径（示例）**：像“办理宿舍手续但日常住校外工会别墅”这类属于**时间线中的状态**（在某时间点成立），不是世界线差异；写前作时只要标清“当时是否已办理/是否已同住/是否已建工会”。  

---

## 6. 使用指南（给你自己和团队）

- 当你写“前作补充世界观”：
  - 先决定：这是补 **世界线**（规则差异）还是补 **时间线**（顺序缺失）  
  - 任何会改变“所有人日常规则”的内容，先停下来：要么另立世界线，要么写场景特批  
  - 只要是时间线补齐，优先通过“前置→发生→后果→回流点”修复，不要改世界规则

- 当你读别人的稿：
  - 看到新设定先问：它影响范围是“全世界”还是“这一段剧情”？  
  - 看到矛盾先问：它是“先后顺序不自洽”还是“世界规则被改了”？
