# Guild Military Demo｜状态栏与数值系统：机制说明 + 代码逻辑索引

> **用途**：给后续 AI / 程序 / 策划 **快速对齐** 本 Unity Demo 里「玩家能看见什么状态」「状态如何变化」「代码在哪些文件里**。  
> **工程路径**：`GuildMilitaryDemo/GuildMilitaryDemo`（脚本在 `Assets/Scripts/`）。  
> **核心单例**：`GameState`（`MonoBehaviour`，`DontDestroyOnLoad`，静态访问 `GameState.I`）。

---

## 1. 界面层级：哪些是「状态栏」

| 界面 / 组件 | 脚本 | 刷新方式 | 展示的数据来源 |
|-------------|------|----------|----------------|
| **主状态 HUD（文字）** | `MainHudUI.cs` | 每帧 `Update()` 读 `GameState.I` | 世界观抬头、`教学周`、游戏日、时间、金币、**欠租提示**、低需求预警、四维、压力、钓鱼摘要、可选诅咒、五声部、阿斯特冷却 |
| **待办列表** | `TodoPanelUI.cs` | 每帧 `Update()` | `GameState.todoItems` |
| **回忆录（日记摘要）** | `DiaryPanelUI.cs` | 每帧 `Update()` | `GameState.diaryEntries`（最近 N 条） |
| **设置** | `SettingsPanelUI.cs` | 打开时 / Toggle 变更 | `PlayerPrefs` + `GameState.Get/SetShowVoiceOverlay()` |
| **选项面板 + 内心声部条** | `DemoChoicePanelUI.cs` | `Show()` 时 | 标题/正文/三选项 + 可选 `innerVoiceLine`（受设置开关控制） |

**未在主 HUD 显示的状态**：

- 魔魔库存、咖啡厅 job 等级等：在 `DemoLifeLoopController` 私有字段，**不在 HUD**。

**欠租**：`RentShortfall == true` 时主 HUD 会显示 **【欠租】** 提示行（与傍晚补救事件一致）。

## 2. 主状态栏 `MainHudUI`（逐行机制）

**文件**：`Assets/Scripts/UI/MainHudUI.cs`

### 2.1 序列化字段

- `statusText`：`TMP_Text`，所有状态拼成多行字符串一次性赋值。
- `showCurseInHud`：是否显示 **诅咒** 一行；默认脚本注释写「诅咒默认不显示」，由 Inspector 勾选控制。
- `showPersonalityInHud`：是否显示 **五声部** 一行；默认 `true`。

### 2.2 显示内容顺序（从上到下）

1. **世界观抬头**  
   - `=== 军校联合学园 · 学生工会 | 档:{GameState.DemoContentTier} ===`（`DemoContentTier` 一般为 `standard`）。

2. **教学周 + 游戏日**  
   - `第{teachingWeek}教学周`，其中 `teachingWeek = GameDayIndex / 7 + 1`（Demo 用「周」便于对齐课务语感）。  
   - `第{GameDayIndex}游戏日`：`GameDayIndex` 为 **从 0 起算** 的「经过的日历日数」（见 §4.3）。

3. **时间行**  
   - `GameState.GetTimeText()` → `{year}年{month}月{day}日 {hour:00}:{minute:00}`

4. **金币**  
   - `gold`，单位文案固定 `G`。

5. **欠租**（条件）  
   - `RentShortfall` 为真时：`【欠租】工会别邸周租未结清，需补缴 {GuildRentWeekly}G 或筹钱。`

6. **需求预警**（条件）  
   - 体力 / 饱食 / 清洁任一项 `< 25` 时一行 `状态: …（日程压力下易升压）`，与 §4.4 中低体/低饱食略增压力增长一致。

7. **需求四维 + 压力**（均为 0～100 浮点，显示为整数）  
   - `fatigue` 文案为 **「体力」**（策划语义：体力/stamina，0 表示昏厥方向）。  
   - `satiety` → **饱食**  
   - `cleanliness` → **清洁**  
   - `stress` → **压力**

8. **钓鱼摘要行**（条件显示）  
   - 当 `GameDayIndex >= GameBalance.NarrativeSchoolDay1GameDayIndex`（叙事「开学 D1」对应索引，常量一般为 `2`）时追加一行：  
     - `钓鱼 Lv{fishingLevel}`  
     - `竿{fishingRodTier}档`  
     - `鱼×{GetTotalFishCount()}`  
     - 若 `joinedAnglerClub` 为真，追加 `垂钓社`。

9. **诅咒行**（可选）  
   - 若 `showCurseInHud`：`诅咒(隐藏): {curse:0}`

10. **五声部行**（可选）  
   - 若 `showPersonalityInHud`：  
     `五声部 理{personality_reason} 血{personality_blood} 视{personality_gaze} 面{personality_face} 月{personality_moon}（选项累计倾向）`

11. **阿斯特借款冷却**  
   - `DaysUntilAsterLoanAvailable()`：从未借过返回 `0`（文案仍为「还剩 0 日」）；借过后为距离 **再可借** 的剩余游戏日数。

### 2.3 不负责的内容

- **不绑定** Slider/Image 条形图，纯文本。  
- **不显示** 待办 / 日记正文（另有面板）。

### 2.4 需求 tick 与 HUD 预警的对应（持续优化说明）

- `TickOneMinute` 中：除原 `stressGainPerMinute` 外，若 `fatigue < 20` 或 `satiety < 20`，压力每分钟额外乘 **1.12 / 1.1**（可叠乘），体现「硬撑上课」的轻微代价；HUD 在 `<25` 时提前文字预警。

## 4. 全局状态 `GameState`：字段与「谁改它」

**文件**：`Assets/Scripts/Core/GameState.cs`

### 4.1 时间与日历

| 字段 / API | 含义 |
|------------|------|
| `year, month, day, hour, minute` | 游戏内日历与钟点；开局默认叙事 `3/1 8:00`（以 Inspector 为准）。 |
| `GameDayIndex` | **私有 set**；在 `AddMinutes` 循环中，当 `day` 相对上一分钟 **发生变化** 时 `++`。首日从 0 开始，跨天递增。 |
| `GetTimeText()` | HUD 用显示字符串。 |

**跨天规则**（`AdvanceClockOneMinute`）：每月固定 **30 天**，12 个月，年递增；与真实历法无关。

### 4.2 经济

| 字段 / API | 含义 |
|------------|------|
| `gold` | 整数金币。 |
| `TrySpendGold(int)` | 不足返回 `false`；足则扣减。 |
| `AddGold(int)` | 增加，且 `Mathf.Max(0, gold + amount)` 防止负金币。 |
| `TryGrantFatherRemittanceWeek1()` | 当 `GameDayIndex` **首次等于** `NarrativeSchoolDay1GameDayIndex` 时在 `AddMinutes` 内调用；加 `GameBalance.FatherRemittanceWeek1`（350G），仅一次。 |
| `TryAsterLoan()` | 若距 `lastAsterLoanGameDayIndex` 未满 `AsterLoanCooldownDays`（14）则失败；否则加 `AsterLoanAmount`（100G）并记录日索引。 |
| `DaysUntilAsterLoanAvailable()` | 从未成功借过（`lastAsterLoanGameDayIndex < 0`）→ `0`；否则 `max(0, 14 - (当前 GameDayIndex - 上次索引))`。 |

### 4.3 周租与欠租

| 字段 / API | 含义 |
|------------|------|
| `RentShortfall` | 周六 10:00 自动扣租 **金币不足** 时置 `true`；足额扣租或补缴成功后清 `false`。 |
| `TryWeeklyRentSaturday1000()` | **每一游戏分钟内**在 `AddMinutes` 循环末尾调用。条件：① `GameDayIndex >= FirstRentSaturdayMinGameDayIndex`（默认 7）；② 当前 `hour==10 && minute==0`；③ 已过叙事 D1；④ `(GameDayIndex - d1) % 7 == 5`（与「D1 为周一」叙事对齐的周六）；⑤ 当日未处理过（`_lastWeeklyRentProcessedGameDayIndex` 去重）。成功扣 `GuildRentWeekly`（200G）并写日记；失败则 `RentShortfall=true`。 |
| `TryPayRentArrears()` | 仅在 `RentShortfall` 且金币 ≥200 时可补缴；扣款、清标记、写日记、并 `MarkTodoCompleted("w1_rent_and_remittance", alsoAddDiary: false)`。 |

### 4.4 需求条（0～100）与每分钟衰减

| 字段 | 初值示例 | 每分钟变化（`TickOneMinute`） |
|------|----------|-------------------------------|
| `fatigue` | 80 | **减少** `fatigueDrainPerMinute * mult`（默认 0.08 × mult） |
| `satiety` | 70 | **减少** `satietyDrainPerMinute`（默认 0.05，**不吃 mult**） |
| `cleanliness` | 60 | **减少** `cleanlinessDrainPerMinute`（默认 0.03，**不吃 mult**） |
| `stress` | 20 | **增加** `stressGainPerMinute`（默认 0.02，**不吃 mult**） |

**复合倍率 `mult`**（只作用于 **体力消耗** `fatigue`）：

- `stressFactor`：`stress > StressCurseThreshold`（70）→ `1.35`，否则 `1`  
- `hungerFactor`：`satiety < 30` → `1.25`，否则 `1`  
- `cleanFactor`：`cleanliness < 30` → `1.15`，否则 `1`  
- `mult = stressFactor * hungerFactor * cleanFactor`

**诅咒增长**：若 `stress > 70`，每分钟 `curse += 0.03`（再经 `ClampAll` 限制在 0～100）。

**可调参数**（Inspector）：`fatigueDrainPerMinute`、`satietyDrainPerMinute`、`cleanlinessDrainPerMinute`、`stressGainPerMinute`。

### 4.5 五声部性格（0～100 整数）

| 字段 | 策划标签 |
|------|----------|
| `personality_reason` | 理 |
| `personality_blood` | 血 |
| `personality_gaze` | 视 |
| `personality_face` | 面 |
| `personality_moon` | 月 |

**修改入口**：`ApplyPersonalityDelta(reason, blood, gaze, face, moon)`，各分量相加后 `Clamp` 到 0～100。  
**调用链**：`DemoLifeLoopController.HandleOptionSelected` → 先 `ApplyPersonalityForChoice(optionId)`（内部再调 `GameState.ApplyPersonalityDelta`）。**与选项 id 绑定的表**在同一文件的大 `switch` 中。

### 4.6 钓鱼（HUD 子集 + 库存）

| 字段 | 含义 |
|------|------|
| `fishingRodTier` | 1～4（0 表示无竿，逻辑里若 <1 不能钓鱼） |
| `fishingLevel` | 1～10 |
| `fishingExp` | 累计经验，对照 `GameBalance.FishingLevelExpThresholds` 升级 |
| `joinedAnglerClub` | 是否入垂钓社（HUD 显示「垂钓社」标签） |
| `fishInventory` | `List<FishCountEntry { species, count }>` |

相关 API：`AddFish`、`GetTotalFishCount`、`SellAllFish`、`TryCookOneFishForMeal`、`TryPurchaseNextFishingRod`、`AddFishingExp`（升级时 `AddDiaryEntry`）。

### 4.7 待办与日记

- `todoItems` / `diaryEntries`：见 §3 与 `DiaryPanelUI`。  
- `AddDiaryEntry(title, content)`：生成 `id`，`dateText` 用当前 `GetDateText()`。

### 4.8 设置（与状态栏间接相关）

- `PlayerPrefsKeyShowVoiceOverlay`：内心声部是否显示。  
- `GetShowVoiceOverlay()` / `SetShowVoiceOverlay(bool)`：**不影响** 五声部数值结算，只影响 `DemoChoicePanelUI` 是否显示灰字旁白。

## 5. 时间推进总线：`AddMinutes`（所有需求/周租/跨天的唯一主入口）

**方法**：`GameState.AddMinutes(int delta)`

对每一分钟 **严格顺序**：

1. `TickOneMinute()` — 需求与诅咒变化（见 §4.4）  
2. `AdvanceClockOneMinute()` — 分钟→小时→日→月→年  
3. 若 `day != prevDay`：  
   - `GameDayIndex++`  
   - 若 `GameDayIndex == NarrativeSchoolDay1GameDayIndex`：`TryGrantFatherRemittanceWeek1()`  
   - 更新 `prevDay`  
4. `TryWeeklyRentSaturday1000()` — 见 §4.3  
5. 循环结束后 `ClampAll()`

**因此**：任何玩法（选项、打工、钓鱼、调试按钮）只要调用 `AddMinutes`，就会 **等价地** 推进上述逻辑。  
**调试**：`TimeAdvanceButton.Advance60Minutes` / `AdvanceOneDay` 仅调用 `AddMinutes`。

## 6. 选项面板与内心声部（非主 HUD，但与「状态展示」相关）

**文件**：`Assets/Scripts/UI/DemoChoicePanelUI.cs`

## 8. 常量对照（经济/叙事锚点）

**文件**：`Assets/Scripts/Core/GameBalance.cs`（节选，以代码为准）

- `GuildRentWeekly = 200`  
- `AsterLoanAmount = 100`，`AsterLoanCooldownDays = 14`

- `NarrativeSchoolDay1GameDayIndex = 2`（Phase0 两日 0～1，叙事 D1 = 索引 2）

- 钓鱼：`FishingRodTierMax`、`FishingSkillLevelMax`、`FishingMinutesPerSession`、`FishingExpPerCatch`、`FishingLevelExpThresholds`、`FishingRodPurchaseGoldForTier`、鱼收购倍率等

## 9. 扩展建议（若要让「状态栏」与策划完全一致）

1. **欠租可视化**：主 HUD 已有文字行；若需更强提示可改 TMP 颜色或加 Icon（未做）。  
2. **条形图**：用 `Slider` 绑定 `fatigue` 等，在 `Update` 中设 `normalizedValue`。  
3. **游戏日 vs 叙事日**：HUD 可同时显示「第 N 游戏日」与「叙事日期」以免策划混淆。  
4. **性能**：主 HUD 可改为 `LateUpdate` 或 **脏标记**（状态变才刷新），当前 Demo 每帧字符串拼接可接受。
